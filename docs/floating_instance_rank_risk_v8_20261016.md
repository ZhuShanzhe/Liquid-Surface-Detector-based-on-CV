# 漂浮物最高实例排序与连续高度误差风险实验

日期 2026-10-16。实验版本 V8。视觉仅用于已选择的漂浮物场景的最高高度，不修改液深，不用于透明、暗光、眩光等其他场景的液深或最高高度。

结论：连续高度校正和风险排序在主动双目上取得改进；最高实例差排序的独立增益很小。V8主策略的独立测试MAE比V5低，但主策略仍有旧分支尾部错误，P95延时略超0.5秒；完整研究策略出现1.288米错误高峰。两种策略均保持实验版，不合并正式默认链路。

## 方法与评估协议

V7的失败揭示了两种不同问题：较低漂浮物可能比最高漂浮物更容易形成高分候选；来源确属漂浮物的平滑回波也可能有系统偏差或顶部统计偏差。V8将物体真实性、实例顶部高度、连续误差风险和最高实例排序分开建模，避免把宽容差内的二元“合格”分数当作毫米级准确度。

复用既有RGB-D像素网络，不重新训练像素分割网络。新增头是轻量梯度提升模型，输入67维原始候选与观测上下文特征。特征包括RGB/深度语义、原始米制高度分位数、逆深度统计、空间支持、空槽底面残差、可疑静态区域的当前与空槽差异、同帧其他候选的相对高度及质量。空槽与当前图的静态差异只是观测证据，不是已知硬件偏置标签。

| 模块 | 监督目标 | 推理作用 |
|---|---|---|
| 物体回波真实性 | 占主导漂浮物连通区域≥60%，且真实漂浮物回波占比≥60% | 排除墙、底部和假回波，不把语义正确等同于最高实例 |
| 连续高度校正 | 对应可见连通区域顶部减去原始q90高度，以噪声尺度归一化 | 学习分位数、匹配噪声及已见分布中的偏差，不使用全帧最高高度替代局部监督 |
| 连续误差风险 | 按安装分3折留出预测所得的绝对高度误差，拟合80%分位数 | 用米制风险筛选/排序候选，不再仅学习是否落入5%容差 |
| 最高实例排序 | 本候选对应区域顶部与全图可见最高区域的高度差 | 给较低实例施加排序惩罚；风险与排名只影响选择，不从报告高度中扣去 |

训练折以安装分组，禁止同一安装的重复帧同时进入校正头训练折和其误差评估折。风险头的特征包含留出预测的校正量及高度。最终校正头使用完整训练集训练；该差异仍可能使推理风险校准不准，需要独立结果核查。

提案保留V5原始候选，额外增加较低语义阈值提案，再恢复原始语义分数作为特征，避免把放大后的置信度当成证据。候选仍是实际深度像素，不增加伪测量点。重叠候选先按实例合并，使用中位高度，降低对同一物体多次噪声试探取最大值的偏差。最小点数/空间格、物理分数与连续风险限制只控制新候选能否采用；不通过时保留V4/V5回退，全帧仍测试，不裁剪高度、不强制归零。原有“最高高度不低于液面”的输出顺序约束不变。

本轮“实例”以可见连通区域近似，并非物体ID级实例分割；接触物体可能合并，同一物体也可能因遮挡拆开。这限制了最高实例监督与分组选择的准确性。对单个平滑斑块，没有独立可靠参考时，未知整块测距漂移与真实高度变化仍可能不可区分；学习校正不能证明该物理歧义已消除。

### 数据与冻结

训练/验证沿用独立的198/99组安装，每组2帧，种子为`202610160317`及`202610160419`。不使用V7测试集训练或选参。验证集决定每种传感器的策略，并允许保持旧方法；同时保存不完全旁路的研究策略。验证选择的主策略在ToF和结构光走V5，主动双目启用新校正与风险排序；双目未选择额外的最高实例差惩罚。

训练共有46,083个候选，15,957个满足物体/回波监督条件。与V7的宽容差二元标签不同，本次高度回归不把“5%以内”视为同等正确；对应区域顶部的每毫米偏差都会进入连续目标。分组留出仅针对本次新增校正头，既有像素网络与V5特征模型作为固定上游使用。

新测试种子`202610163811`，264组独立安装、528帧，实际包含480帧有漂浮物及48帧干槽对照。液深按0.01–0.1、0.1–1、1–2……8–9m分层；相机到底面≤10m。输入仍为同一空槽建模链路及模拟带噪操作标定，不向推理提供真实容器几何或测试液深。校准输入不合格时重新标注后测量，而不是依据误差排除帧。

测试前冻结代码、权重及验证策略SHA256；全部方法逐帧配对，顺序循环轮换，GPU预热后计时。模型初始化、磁盘读取、相机采集与GUI不计入`measure`算法耗时。最终成绩是同一渲染器和传感器代理分布的新种子测试，不等于真实相机验收。

最高高度评价相对容器内底面的物理网格最高点，容差为`max(50mm, 5%真实最高高度)`；液深容差为`max(20mm, 2%真实液深)`。绝对误差和相对误差分别报告，干槽不计算相对误差。不得将可见连通区域的顶部监督与最终物理网格最高点真值混为一谈。

### 对照版本

- V4和V5：原有代码及模型，不修改。
- V8主策略：验证集选定策略，允许传感器旁路旧方法。
- V8研究策略：验证集选定、仍尝试新模型的策略，不因新测试结果调整。
- V8无排名消融：研究策略的其他参数保持不变，仅将最高实例差惩罚权重置0；与研究策略比较才可判断该惩罚的增益，不能与主策略的旁路差异混为一谈。

## 最高实例选择与误差风险的诊断

研究策略在480帧中467帧采用新候选，13帧回退。全部候选中有446帧包含最高实例，说明34帧仍缺少满足纯度条件的最高实例候选。467次采用中，447次所选候选真实属于漂浮物，其中384次匹配最高实例、63次仍选中较低实例，另20次采用的区域不满足真实物体/回波条件。

仅去掉最高实例差惩罚，其余研究参数保持不变，真实最高实例选中数为382次；加入后为384次。超过5mm改善9帧、退化7帧，464帧差异≤5mm，通过率不变；MAE差的95%区间约−1.08～+0.14mm跨0。因此主要改善不能归功于该排名头。排序仍需要更可靠的实例区域与小最高物体证据。

研究策略所选真实漂浮物候选的区域顶部MAE20.61mm，风险区间经验覆盖率79.19%；主策略双目所选真实候选的覆盖率73.05%。这些均以“选中区域确实是漂浮物”为条件，排除了错误物体候选，不能作为整帧测量置信度保证。当前风险头只在真实漂浮物候选上训练，对错误区域的风险可能严重低估。

主策略37个超标帧分解：19帧验证旁路V5，6帧新候选未采用后回退，5帧最高实例的高度仍不准，6帧选择较低实例，1帧误接纳非目标区域。这些是测量后真值审计，不参与运行时选择。

### 研究策略的1.288米异常

新集ToF case303 repeat0：真实最高3.374892m，输出4.663025m，误差1288.13mm；同帧V4误差4.74mm、V5误差2.49mm。新候选只有6点、二维包围盒约5×2像素、2个空间格，物理分数0.9846、预测风险13.52mm、预测最高实例差1.11mm，但离线审计确认并非真实漂浮物区域。实际最高实例候选原本存在，是可信度与排序的误接纳，而不是传感器完全没看见最高物。

V8为保留小漂浮物而在验证中允许4/8点、2格，未沿用V7的完整≥12点、二维跨度和空间留出硬检查。这种放宽在独立集造成明显反例，说明学习分数不能替代孤立峰硬证据。只训练真实候选的连续风险也不能覆盖“候选身份本来就错”的错误。

### 主策略的不足

主策略最大381.51mm来自结构光case711 repeat1，沿用V5，并非新校正头输出。主动双目case1227回退后仍达360.63mm。主策略真正采用新候选的最大误差为243.97mm，发生于case1011 repeat1：真实最高0.343042m，输出0.099074m；所选区域不是真实漂浮物，物理分数0.9396、预测风险147.55mm，且最高实例候选缺失。它说明新头既不能凭空恢复未形成候选的最高物体，也可能在高噪声区域用过低的物理门槛接受错误区域。

## 延时与隔离验证

主策略算法延时中位252ms、P95 507ms、最大837ms，5.625%的有漂浮物帧超过500ms；主动双目单类P95约562ms。研究策略P95约565ms，23.33%帧超过500ms。因此没有达到严格逐帧0.5秒要求。主策略两类传感器的加速主要来自V5等价包围盒特征实现及旁路新增计算，不能说是新视觉网络本身更快。

共2640条主测试方法记录中，液深相对V4变化数为0。480帧液深MAE24.16mm、P95 106.69mm、通过率85.83%，五路完全相同；本次未优化液深。共同偏移诊断中，同一偏移输入的各路液深也一致。

全套测试688项通过、14条原有警告。无USB公共入口五项调用验证通过：开启、关闭、研究版、无排名消融、其他场景显式请求但提供不存在模型路径。后者不加载模型，所有调用液深相同。一次训练过程的紧凑缓存读取缺少mask已修复为读取既有空间格特征，重新训练完成；失败日志保留，不计入完成结果。

## 是否合并与后续优先级

不修改`configs/application_route.json`，正式默认继续使用旧确定版。V8主策略及研究策略都作为显式可选实验保存。双目连续校正的改善值得保留研究，但以下问题阻止整体合并：研究版新灾难性高峰；主策略继承V5已知ToF异常；部分浅液位与1–2m区间未改善；P95和最慢帧延时未达0.5秒。

下一轮优先恢复V7的孤立峰硬约束，小于充分二维支持的最高物体使用多帧支持确认，而不是让高分类分数豁免。将错误区域和错误回波纳入联合风险监督，区分“身份错误风险”和“身份正确后的高度风险”；增加容器边缘、薄条墙面、孤立小块的困难负例。最高实例排序需物体ID级监督、实例均衡采样及候选缺失诊断，不能只增大一个排序权重。对于平滑共同偏差，应优先验证可观测静态锚点和传感器域偏移估计；无可靠锚点时明确报告风险，不把学习先验当作绝对偏置校正。

后续只在训练/验证上修改策略，并换另一独立种子复验，不根据本测试逐帧真值拼接版本。
