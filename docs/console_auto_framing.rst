ToF仿真控制台：可变容器与自动构图
================================

版本：scene_console_v5_qualified_inputs_20261020。保留浏览器入口，暂不打包桌面软件。
展示适配不替换正式液深计量核心，也不构成硬件精度认证。

使用流程
--------

1. 输入容器内高度、相机到底面距离与液体类型。容器目前为内直径1.10m的竖直圆柱，
   相机位于中心正上方，垂直向下；不是侧视或持续移动相机。
2. 默认勾选“自动构图”。系统尝试以54°–100°水平视场容纳完整槽口并保留12%边距；
   当前距离不足时自动上移相机，实际采用的距离回填到输入框，结果的framing字段保留请求值。
   距离上限10m。无法满足时拒绝该工况，而不假造超广角、不缩小容器或裁剪液位结果。
3. 点击“应用工况并测量”。首次、安装尺寸/有效距离/视场/材质改变时自动重新采集空槽，
   重建几何、相机内参和先验；仅改变液位、光照、漂浮物等时复用相同安装。
4. 透明/半透明另建一空槽加四帧已知液深先验，液深分别为容器高度的0%、10%、35%、65%、95%。
   AMCW校准使用该次真实仿真内参的焦距，不再写死470.94px。
5. 结果始终相对容器内底面。三维视图在安装变化时复位并按容器高度自动适配，
   “相机位置”用于显示顶部安装；拖动/滚轮只改变展示视角，不改变传感器内参。

自动构图约束
------------

本展示分辨率480×270，半径r=0.55m，宽高比a=480/270，边距系数m=1.12。
为完整看见槽口，上方净空至少为 r*m*a/tan(100°/2)。
实际相机到底面 B=max(请求B, 容器高C+该净空)，自动上移时向上取整到毫米。
水平视场为clip(2*atan(r*m*a/(B-C)),54°,100°)。
Blender采集、空槽与湿槽内参、五帧相位先验、输出安装元数据保持一致。
网页画布缩放完全独立，不能替代上述物理视场修改。

这些是虚拟ToF镜头的展示设置，不表示同一台商业传感器能连续变焦。
实际部署应输入厂商内参与固定视场，并通过安装距离或实际容器尺寸满足视野约束。
改变视场会改变角分辨率和目标像素数，本次回归与旧54°独立测试必须分开统计。

初始化信息的来源
----------------

仿真自动提供独立的底面距离、重力、容器尺寸和空槽图；当前湿槽真值只在测量后用于评分。
正常情况下仍由完整空槽轮廓和独立标尺建模。关闭自动构图后，如边界不在图内，
可采用“独立已知容器尺寸/安装位姿+空槽底面一致性检查”的仿真方式。
它不声称从不可见轮廓估计完整尺寸；现场必须真的测量这些先验，否则不能使用该方式。
空槽与独立尺寸冲突时仍报错，绝不以仿真设定覆盖矛盾的空槽数据。

范围与测试解释
--------------

* 普通液体允许低照、眩光、部分缺失0%–50%、起伏、漂浮物的有限组合。
* 透明/半透明只支持均匀、近似平面、无遮挡；与漂浮物/起伏组合仍拒绝。
* 透明RGB外观与解析AMCW传输尚未联合建模；其光照复合测试属于接入回归，不是对应退化认证。
* 不强制归零、不裁剪测量值；警告与错误保留，数值输出不等于可信或达标。
* 原正式分类仍是默认CLI入口；服务器可选的V10实验工厂通过独立启动脚本使用，
  不把参数网格测试替换为既有大样本正式性能报告。

启动与验证
----------

原默认入口：scripts/launch_scene_console.sh，只绑定服务器127.0.0.1。
服务器实验演示使用 liquid-depth-artifacts/console-autoframe-v4-20261020/launch_console_v3.py，
可传 --port 与 --work；该脚本名称沿用测试时名称，实际软件版本由/api/status明确返回V4。
其V10依赖与权重保留在已归档的latency-final-v10-20261020及前置研究目录，未改正式算法默认值。
发布前若需完全可移植打包，应先将实验运行时及其权重按许可证整理，不直接依赖研究目录。

相关测试：tests/test_console_installation.py、test_unified_tof.py、test_small_float_peak.py、
test_compound_tof_repair.py；源文件与完整仿真输入输出均在服务器留档。

前置输入资格与跳过策略
----------------------

按用户要求，先审查输入，再执行分类与测量。不合格帧只显示“输入不合格·未处理”，
不输出估计液深或最高高度，不构建测量点云，不进入误差、通过率、数值覆盖率、分类或延时分母。
界面仍可显示已生成的仿真场景预览，以便操作人员调整设置；采集/资格审查不等于运行测量。

普通液体需满足真实可见液面深度缺失率≤50%、至少30个有效点及横纵最小跨度3像素；
漂浮物另需至少3个有效可见点及最小跨度2像素。透明/半透明依据原始AMCW调制有效率判断，
不把普通液体的深度空洞规则套用到相位链路。不会按估计误差或正确返回数量筛选。

上述资格检查在仿真适配层使用生产器的独立可见性标签，标签不传入任何测量模型。
它不是现场可用的真值掩码；现场仍需独立实现可部署的可观测性判断。
sim_input_qualification.py及插桩回放验证了所有跳过帧的分类器/测量调用均为0。
V5服务器实验启动脚本位于liquid-depth-artifacts/console-qualified-v5-20261020/。

本版本未包含真实相机USB/SDK驱动，也未与PLC控制联动。
