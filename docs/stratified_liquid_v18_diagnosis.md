# 顶部相机下多种透明液体分层：V18 前置诊断

## 结论与任务边界

用户的分类意见总体合理：顶部采集、容器内只有一种透明或半透明液体、目标是自由液面时，继续归入既有单液体任务。容器壁、底面和错误回波作为干扰项，不单列为“多层液体”。V17 适配冻结，本轮没有改动其权重或生产默认。

顶部部署不等于整个视场完全没有侧壁：透视视角、相机偏心或倾斜、收口/锥形容器，以及边缘折射都可能使内壁进入视野。只有近似垂直、中心视野、开口无遮挡等条件下，壁面影响才较小；这些情况仍属于原任务的边缘干扰。

**本轮“多层透明”专指两种或更多互不相溶、稳定分层的透明液体。** 第一阶段目标是从顶部识别空气—液体上表面和内部液—液界面，判断是否分层，并估计各层厚度。容器底面只作为可能需要获取的参照，不能拿壁面或底面预测冒充内部液—液界面。

本轮完成代码/数据契约审计、解析光学算例和评价方法诊断。**尚未生成经验证的真实双液体图像数据，也没有训练双液体模型，因此目前不能给出油水等多液体场景的检测率或毫米级精度。** 旧 V9/V12 的“multilayer”指标以及 V17 单液体指标均不能替代它。

## 已确认的不足及原因

| 环节 | 代码或实验依据 | 对新任务的影响 |
|---|---|---|
| 场景定义 | SyntheticScene 只有一组 liquid_ior、liquid_color_rgb、liquid_turbidity 等参数 | 没有液体列表、内部界面高度或分层拓扑 |
| RGB 生成 | create_liquid 只创建一个 liquid_volume，使用一种液体材质 | 模型没有见过真正的两种液体相接 |
| 深度标签 | render_geometric_labels 合并壁面、单个自由液面和底面 | 四个深度槽位不等于四层液体，更不是内部界面的监督 |
| 原始深度模拟 | 主要由单液面深度、最远几何层、丢失和偏差生成 | 不包含液—液界面回波竞争；不能靠再加随机候选补足物理信息 |
| 模型身份 | 界面损失只与一个 liquid_depth_m 匹配；选择器最后只输出一个深度 | 不具备“上表面/内部界面/壁面/底面”同时识别的契约 |
| V17 拟合 | 对一组预测液面点拟合一个平面 | 直接把多个液体界面的点混在一起会拟合成错误折中面 |
| 旧多层评价 | 每个真值独立寻找最近预测，允许重复使用同一个预测 | 薄层可能被合并却仍算全部命中 |
| 层间分离约束 | 默认最小间距为 max(3 mm, 相机深度的 1%) | 在 0.5 m 处会推动间距达到 5 mm，对真实 2 mm 薄层存在冲突 |

本次核对的旧清单共 12000 行，其中名为 multilayer 的场景有 1620 行。这个类别名称不能证明存在多种液体：对应生成器仍是一种液体，标签事件仍是壁面、单液面与底面。

代码依据：

- src/liquid_depth/simulation.py：SyntheticScene、render_geometric_labels、simulate_raw_depth。
- scripts/generate_synthetic_liquid.py：create_liquid、configure_render。
- src/liquid_depth/models/layered.py：PermutationInvariantLayerLoss、select_liquid_interface。
- scripts/train_transparent_multilayer.py：evaluate 中的最近邻逐层匹配。
- src/liquid_depth/models/precision_v17.py：单液面稳健拟合。

## 顶部观察为什么可能更难识别内部界面

### 1. 去掉侧壁干扰，不等于增加了内部界面的证据

顶部视角下，不同界面会覆盖相似的图像区域；在均匀背景、平整液面、接近法向观察时，内部界面可能缺少清晰轮廓。若液体光学性质接近，单幅图像中的分层证据会变弱。侧壁干扰减少和内部界面可辨认是两个不同问题。

介质界面的反射和折射由折射率比及入射角决定。本轮按 Fresnel/Snell 关系计算控制算例，公式依据为 [PBRT：Specular Reflection and Transmission](https://www.pbr-book.org/4ed/Reflection_Models/Specular_Reflection_and_Transmission)。以下数值使用示例折射率，不代表所有油类或实际设备工作波长。

| 两侧折射率 | 法向反射功率占比 |
|---|---:|
| 空气 1.000 / 示例上层液体 1.470 | 3.6208% |
| 示例液体 1.470 / 1.333 | 0.2389% |
| 示例液体 1.370 / 1.333 | 0.01874% |
| 示例液体 1.343 / 1.333 | 0.001396% |
| 折射率完全相同的控制组 | 0 |

这不是 RGB 图像对比度，也不是传感器检测概率；还没有计入照明、吸收、散射、容器和相机响应。

在相同折射率、无吸收/散射/弯月面差异的理想平层控制中，把内部界面移动 40 mm，不改变计算出的底部光线路径和近轴视深，内部 Fresnel 反射仍为零。这说明**某些退化条件下信息本身不足**，但不能据此认定所有油水场景都不可测。

### 2. 下层的视觉位置与几何位置不同

本轮另做 Snell 光路检查：上层厚 20 mm、下层厚 80 mm，折射率分别为 1.47、1.333。斜视时，穿过两层后落到底部的位置与未折射直线光路不同。因此，后续标签必须区分真实几何界面和折射路径对应关系。

一个直观的近轴例子：透过折射率 1.47 的上层观察其下方界面，20 mm 的实际层厚对应约 13.61 mm 的视觉视深。直接按空气中的几何关系反推会产生约 6.39 mm 偏差。**这只是近轴视觉模型，不是 ToF 深度输出公式。**

### 3. 当前快速渲染链路需要重新验证

旧数据生成以 EEVEE 为主。Blender 4.2 官方文档说明其折射事件建模存在限制，第二次折射依赖厚度近似；不能直接把这条链路视为已验证的多介质仿真。[Blender 4.2 EEVEE 限制](https://docs.blender.org/manual/zh-hant/4.2/render/eevee/limitations/limitations.html)

后续应建立能追踪多次介质转换的参考渲染，检查介质两侧折射率、共享界面法线、吸收与透射路径，并通过平层解析算例验证。简单叠两个各自按“空气—液体”处理的透明物体，可能引入虚假的双界面。即使 RGB 渲染正确，也仍需单独验证 RGB-D 传感器响应。

## 评价错误的最小复现

真值两个界面分别在 0.5000 m、0.5050 m；模型只预测一个点 0.5025 m。

- 旧逐层最近邻评分：两个真值都在容差内，层召回为 100%。
- 新一对一匹配：同一个预测只能解释一个界面，层召回为 50%，完整集合不通过。
- 因此，“候选离每个真值都近”与“真的分出了两层”不是同一件事。

另外，两个界面各自只有 5 mm 的误差，也可能让 2 mm 的真实薄层出现错误顺序或很大的层厚误差。相机距离的 2% 容差不能单独承担薄液层验收。

已新增独立诊断函数，使用最大匹配数优先的一对一分配，再最小化归一化匹配误差。它只接收已经判定为有效输出的界面集合，额外输出假层会降低精确率。深度匹配本身仍不能认证界面语义；正式评估还应核对身份。

## 后续实施顺序与输入约束

### 第一阶段：先建立真正的双液体数据和标签

- 两层稳定分层为正样本；单液体为无内部界面负样本。
- 覆盖薄层、厚层、折射率接近、相机偏心/轻微倾斜、弱纹理、高光与容器边缘干扰。
- 不把液体颜色与层号固定绑定，避免模型只按颜色或容器形状猜测分层。
- 为上表面、内部界面、壁面、底面分别标身份和可见性；不可观察的内部界面可以有几何真值，但应单独标记可观测条件。
- 折射率、真实层厚、密度和真实位姿仅作为仿真生成/监督参数，不提供给推理。
- RGB 与深度模拟分别验证，禁止直接随机指定真实内部界面深度为观测来制造“容易数据”。

### 第二阶段：先比较可观测性，再比较模型

保留顶部 RGB-D 为基础输入，比较 RGB、RGB-D、可实际采集的多帧信息各自带来的增益。对于退化场景，受控照明变化、可见参照图案或额外视角只能在采集与标定进入实际链路后使用，不能从仿真元数据直接取参数。

已有四分量集合表示可作为一个研究起点；需要新增多个液体界面的身份与存在性，并保留“信息不足”输出。单平面模型只用于各界面的分别重建；若使用共同法向，应从观测或设备姿态测量估计，不能读取真值位姿。

本轮没有在缺少正确任务数据的情况下继续微调 V17，也没有假定相机 SDK 能直接提供多回波或折射率。

### 第三阶段：按层厚任务评价

至少分别报告：

1. 无分层/有分层识别，内部界面数量错误率；
2. 一对一匹配后的界面召回、精确率及身份正确率；
3. 每个界面深度 MAE、P95、P99，完整双界面成功率；
4. 上层厚度 MAE、P95，以及误差不超过 1/2/5 mm 的比例；
5. 误接受、拒绝率、有效覆盖率、按薄层和光学差异分组结果；
6. 若要测最下层厚度，必须把底面参考的获取与误差计入链路。

1/2/5 mm 仅是拟报告的诊断档位，不是本轮已经达到或与用户约定的验收标准。上层厚度应沿液面法向计算；相机轴向深度差只有在相应几何条件成立时才等于真实层厚。

数据按容器、液体组合和采集序列隔离训练/验证/测试，模型选择前固定评价规则。原透明/半透明模型维持冻结，作为上表面基线。
