# V15 液面模型深入优化与清理报告

## 结论

完成三组深度训练、七组可信度实验，以及新独立场景的四种输入条件测试。正常输入下出现了值得保留的深度预测收益，但大尺度偏差和可信度迁移仍未解决，**没有切换生产默认模型**。

- **透明液体：保留常规鲁棒 DFNet。** 新场景 MAE 从 95.96 mm 降至 50.27 mm。正确恢复率从 53.45% 升至 59.61%，但这项通过率增益的 95% 区间跨过零。
- **半透明液体：保留强化 DFNet。** 正确恢复率从 47.99% 升至 63.33%，MAE 从 41.18 mm 降至 29.01 mm。该结果使强化 DFNet 也成为半透明场景下一轮的主要研究对象。
- **可信度实验未通过。** 局部与整图上下文分支都没有满足预先设定的精度、覆盖率及误输出门槛；诊断阈值 0.5 下，新分支在正常透明/半透明测试上的覆盖率均为零。
- **发现数据输入契约的限制。** 仿真把液面以外的原始深度全部置零；现有运行接口则接收整幅深度图。模型比较和性能结论必须限定在这个仿真输入条件下。

所有指标仍是轴向相机深度，容差 max(5 mm, 2%)，**不是容器底面标定后的最终液深精度**。

## 1. 实际完成的优化

### 深度模型

在官方 DFNet 的基础上进行液面监督训练，并加入连续深度修正分支。修正分支使用 RGB、原始深度及有效性、DFNet 深度、冻结 V9.1 的单深度先验和预测掩码等观测信息；不在推理中使用真值。它不进行离散候选选择。

| 训练组 | 设置 | 验证选择结果 |
|---|---|---|
| 普通液面微调 | 干净输入、log1p 归一化深度损失 | 6 轮均未超过综合门槛，保留 epoch 0 |
| 常规鲁棒微调 | 干净、全局偏差、局部错误回波、缺失混合 | 选择 epoch 5 |
| 强化鲁棒微调 | 全局偏差比例提高至 50%，使用更重视大误差的 Huber 损失 | 选择 epoch 3 |

每组深度训练 6 轮，每轮抽样 3072 帧，batch 8。冻结预训练 BatchNorm 统计；DFNet 学习率 1e-4，修正分支 3e-4。

常规扰动：40% 干净、20% 全局偏差、20% 局部偏差、20% 随机缺失。强化组：50% 全局偏差，干净、局部、缺失各约 16.7%。全局偏差训练范围为正负 1–6%，局部偏差为正负 3–12%。

权重选择首先要求透明场景干净输入的正确恢复率不低于原模型超过 3 个百分点，再比较干净与 +5% 偏移条件的综合分数。综合分数允许两项之间的小幅权衡，因此不能把“被选中”解释为每一种条件都改善。

### 可信度与半透明整体拟合

- 深度模型选定后再训练“该点是否在容差内正确”的二分类分支，避免用未训练的分数做筛选。
- 局部分支训练 3 轮；加入冻结语义特征与整图平均特征的上下文分支训练 4 轮；每轮 2048 帧。
- 半透明分支保留 V12 选出的深度，再进行整体稳健平面拟合，分别验证局部、整图上下文可信度。
- 校准和阈值使用独立验证序列。
- 接受门槛：每一种指定验证条件下，接受点正确率至少 80%、有效像素覆盖率至少 10%、非目标输出比例不超过 10%。这只是研究筛选门槛，不是工业验收标准。
- 七个可信度配置的阈值选择均返回空值，没有合格配置。

强化损失与上下文实验是在开发集暴露问题后增加的，设置均在查看新测试结果前声明。没有根据新测试结果重新训练或调整阈值。

### 收益的统计范围

以原 DFNet 为对照，采用 2000 次独立场景成对 bootstrap：

- 常规鲁棒版的透明正确恢复率增加 6.16 个百分点，95% 区间 **[-3.06, +15.21]**；尚不能确认通过率稳定提升。
- 透明 MAE 减少 45.69 mm，误差差值的区间为 **[-95.12, -8.18] mm**，支持平均误差改善。
- 强化版的半透明正确恢复率增加 15.34 个百分点，区间 **[+5.85, +25.24]**。
- 半透明 MAE 减少 12.17 mm，误差差值区间 **[-27.49, -0.71] mm**。

每类只有 64 个独立场景；只有一套训练种子，没有进行多重比较校正。这些是探索性结果。

## 4. 较大深度偏差仍未解决

| 方法 | 透明：正常 / +8% / -8% | 半透明：正常 / +8% / -8% |
|---|---:|---:|
| 原 DFNet | 53.45% / 3.36% / 4.49% | 47.99% / 1.44% / 14.63% |
| 常规鲁棒 DFNet | 59.61% / 3.56% / 4.43% | 58.04% / 1.66% / 10.98% |
| 强化 DFNet | 57.87% / 5.71% / 4.89% | 63.33% / 1.54% / 8.45% |

强化版在开发集 +5% 条件下的改善，未转化为对新场景 ±8% 偏差的可靠处理。透明 +8% 条件的增益区间仍跨过零，半透明负偏差条件还出现回退。

这些是人工压力测试，不代表已经测得相机有相同幅度的真实误差。其意义是暴露模型对错误尺度的依赖，不能据此宣布相机达到物理极限。

## 5. 可信度结果：失败必须保留在结论中

局部和整图上下文分支都已实际训练。上下文降低了部分训练损失，但没有通过独立阈值验证。

全局校准混合了不同材料及输入条件；在本轮测试中，新分支的校准分数没有达到 0.5，诊断阈值 0.5 下透明和半透明的覆盖率都是 0。**这不能解释为高精度或可靠拒绝机制成功。**

正常透明场景的 ECE，常规鲁棒版约 30.43%，强化版约 28.50%，强化版加上下文约 27.82%；旧 V12 校准参考约 6.54%。混合条件校准在正常输入下也出现明显低估，不能继续复用到生产。

因此保留的是深度预测研究权重，可信度策略不启用。失败的分支已经清理，其报告、校准记录和哈希保留。

## 6. 核实的数据问题与后续优先级

### 已确认的事实

新测试四类场景中，液面以外原始深度有效率均为 **0%**。源代码与统计一致：

- src/liquid_depth/simulation.py 的 simulate_raw_depth 从液面真值区域初始化原始深度，区域外置零。
- src/liquid_depth/surface_video_runtime.py 的 SequencePredictor.predict 会编码传入的整幅深度图，没有先按液面真值区域置零。

这意味着当前仿真数据缺少容器和背景的原始深度上下文，还提供了理想化的液面支持范围。它可能导致训练与实际输入不一致；其影响尚未通过完整场景数据的对照实验量化。

V14 对外部模型的排序也应限定为这种 ROI-only 输入条件，不能推广为完整场景 RGB-D 下的模型能力结论。原 V14 报告已补充说明，原交付压缩包仍保留历史版本。

### 接下来应做的工作

1. 优先建立包含容器、背景及液面的完整 RGB-D 训练输入，保留表面身份标签，并验证与真实运行输入的约定一致。
2. 在修正的数据上复测两份保留权重及原模型，分别观察背景上下文、液面身份和尺度偏差的影响。
3. 以独立标定的容器/背景几何或实测参考检查系统性尺度偏差；背景深度本身不自动提供正确的绝对尺度。
4. 再验证按材料校准和跨场景拒绝机制，避免在当前零覆盖率结果上继续调测试阈值。
5. 最终用真实相机、底面标定和已知液深，检查可靠点分布、液面重建与最终液深误差。

本轮新增 audit_depth_context_v15.py；使用 --expect-full-frame 可在缺少背景深度时阻止将该数据描述为完整场景 RGB-D 基准。没有把未经验证的背景深度填入现有数据，也没有改写已完成实验的数据。
