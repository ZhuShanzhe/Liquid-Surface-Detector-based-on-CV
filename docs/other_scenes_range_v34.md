# 其他场景分液深误差分布与后续优化优先级

日期：2026年10月12日。

## 结论与下一步

下一步优先处理普通场景中暴露的液面掩码和容器范围约束问题，再处理正确选点之后的远距离浅液位偏差。当前不宜先投入更复杂的暗光网络，也不宜直接扩大深度修复网络训练。透明、半透明研究链路保持冻结。

这批带完整背景的新测试中，现有自动选点尚不能支持“其他场景在整个液深范围已适配”的结论。普通场景的传感器域候选 MAE 为 1283.23 mm；仅在离线诊断中换成真实液面掩码后，同一批可比较的371帧为 17.34 mm。这说明大量误差来自选错区域及背景污染，不能主要归因于 RGB-D 硬件原理极限。真实掩码结果不是可部署性能，也不意味着剩余误差已达标。

### 当前各场景的主要问题

| 场景 | 当前主要不足 | 下一步优先级 |
|---|---|---|
| 普通 | 自动掩码混入背景，宽松传感器域估计可拟合到错误区域；空槽及浅液位另有远端偏差 | 第一，先修公共选点与容器约束 |
| 眩光 | 掩码污染叠加真实液面空洞；正确掩码也有无解和长尾 | 公共问题修复后优先 |
| 低照 | 选点仍不稳，简单提亮并未可靠改善测量 | 与眩光分开优化，不默认启用提亮 |
| 漂浮物 | 自动掩码和异物回波混杂；当前小漂浮物测试不代表高遮挡覆盖 | 公共问题修复后做异物剔除 |
| 波动 | 平均液深尚有尾部，最浅和最深不能由平均值合格代替 | 保留分区表达，单独核验极值 |
| 大面积失效 | 背景可冒充有效锚点，数值输出率虚高；真实表面支持不足 | 先修锚点归属，再核验时序链路 |
| 多层透明及极端复合 | 本轮未生成对应的可靠全量程新基准 | 不宣称已适配，保持既定研究边界 |

## 评价范围和解释

本轮是冻结权重的独立仿真筛查，不是新的训练或优化成果。新增594张RGB场景图、3564个帧条件，六种场景采用99组配对几何配置；每个场景和液深格含9组配置、每组4次深度噪声重复。四张重复RGB-D帧共用静态RGB，不能视为四个独立容器或真实视频运动。

实际液深为液面相对容器内底面的重力方向面积均值。测试实际液深为0至8.8993 m，位于要求的0至9 m范围内；相机到底面最大9.9122 m。按空槽、0–0.1 m、0.1–1 m以及各1 m区间均衡分层，并不是把0至9 m连续均匀抽样后计算自然频率。浅液位和空槽在汇总中被有意提高权重，汇总成绩不能直接当成现场场景频率下的平均性能。

每个配置提供理想内参、位姿、底面和容器几何，没有额外的已知液深先验图；这与透明链路的五帧折射标定不同。容器内底面与外壳底面区分，未把壁厚算作液深。不同液深对应不同容器配置，本轮不验证同一固定容器的全程注排液。

空槽组还有一项仿真边界：传感器目标使用解析内底平面，但当前无液体渲染没有独立的完整干槽内底网格，背景台面比该标称内底低3 mm。空槽结果只能作为零位管线的代理诊断，不能作为严格的真实干槽零位验收。下一轮普通场景实验应先补齐干槽实体底面，并重新单列零位测试；非空槽液面测试不依赖这项干槽渲染。

普通、低照、眩光、漂浮物、波动与失效均采用有可见表面回波的非透射液面；不是透明链路的替代测试。液面大约占百像素量级，不针对此前放弃的小像素容器优化。视角为接近垂直的顶部视角，不代表任意侧视。深度噪声、错误回波和空洞来自参数化传感器代理；不是实际双目、结构光或ToF设备的精度认证。

### 方法与指标

- `v8_neural`：冻结V8网络的预测掩码和修复深度，使用已修正的底面相对液深统计。
- `raw_grid`：同一个V8预测掩码，加原始深度；在标定容器水平轮廓内建立网格并统计。它本身有空间支撑要求，不能把未输出帧算作成功。
- `refined`：现有研究型传感器域稳健估计。平稳表面用双目或结构光视差似然，ToF用均衡高度；波动用现有局部分区插值。它不是操作面板的默认生产链路，也不是独立RGB校验后的可信输出。
- `v6_optional`：低照、眩光和失效配置中已有但默认关闭的V6网络候选，不按测试真值选最优模型。
- `exposure_refined`：低照下启用已有的有界gamma与CLAHE前处理，再用相同冻结V8网络选点。仅作对照，未修改默认开关。
- `oracle_mask_refined`：仅在评估器中使用真实可见液面掩码，隔离选点影响，绝不能当作产品结果。

MAE、P95及误差直方图基于实际液深误差，而不是到相机的距离误差。P95是有值帧绝对误差的95分位数。绝对误差分箱占全部帧的比例，未输出另列；相对误差分箱占非空槽且有值帧的比例。空槽的相对误差未定义，只看毫米误差。通过阈值仍为 `max(5 mm, 2% × 真实液深)`；它只是辅助指标，1%以内、2%–5%以及更大的误差占比另列。

不强制归零、不把液深裁剪到0或容器容量、不按置信度筛掉高误差帧。保留算法自身无法形成数值的情况。原几何接口即使因负液深标记拒绝，只要已计算出统计值，本轮也保留该数值用于诊断。因此表中的有值率不等于产品合格覆盖率，更不等于这些帧可以安全发布。

## 根因分析

普通场景平均预测掩码IoU仅0.3781。超标帧的平均IoU为0.0961，合格帧为0.7421；对应的相机至液面平均垂直距离约4.38 m和1.20 m。选点失败与远端退化同时存在，这些相关统计不能把两个因素完全分离。

在371个双方均有值的普通帧上，原传感器域估计MAE为1283.23 mm、真实掩码对照为17.34 mm，87.60%的同帧误差下降。低照352帧对应1062.12至12.76 mm，眩光320帧对应1538.52至14.79 mm，漂浮物371帧对应1059.01至19.34 mm。以上同帧对照支持“选点是主要可修复瓶颈”，不能解释为仅更换一个可用模型已经得到这些收益。

代码层面，现有传感器域支撑提取先取预测掩码中的原始有效深度，并按图像网格均衡。容器轮廓参与面积统计，但该支撑提取没有先强制限制所有点的实际世界XY位置。掩码漏到背景时，远处桌面、容器外表面也可能获得大量票数，稳健估计会稳定地估计错误的层。相比之下，`raw_grid`显式限制世界XY范围，因此有时误差更小，但输出率也更低。不能把两种不同有值子集的汇总差直接视为同帧改善。

几何和单位检查中，真实深度加真实掩码经过同一坐标转换后，3564帧的平均误差为0.001395 mm，P95为0.006360 mm，最大0.132961 mm。该检查支持本轮坐标与单位实现一致，不说明模型或硬件有亚毫米能力。

即便排除选点问题，普通场景真实掩码对照在空槽、0–0.1 m、0.1–1 m的MAE仍分别为30.50、23.16、18.09 mm。因此公共选点修复之后，远端视差噪声、截断、错误回波和零位校准仍须继续处理，不能只修掩码就宣布完成。

7–9 m液深组明显更好，不代表相机在7–9 m测距时更准。相机到底面不超过10 m的约束使深液位组的相机更靠近液面；背景量程截断也随之改变。不能把这种测试构成差异解释为模型天然偏爱深液位，后续应同时按液深H和相机至液面距离Z分层。

低照的简单提亮对照全帧通过率由52.78%降至45.96%，有值MAE由1067.47增至1211.65 mm。它在这批数据中没有形成可默认启用的改进；后续应先处理任务相关选点和噪声，不以图像看起来变亮为成功标准。

波动场景现有分区估计的平均液深MAE为61.50 mm，但最浅、最深液深MAE分别为607.68和176.94 mm。真实掩码对照仍有36.92 mm的平均液深MAE，最浅和最深分别为686.56和184.78 mm。当前分区插值对稀疏支持、错误回波及极值很敏感，不能把面积均值还可以解释为波峰波谷已恢复。

## 容器范围约束的事后诊断

以下实验是在发现问题后对同一批帧做的原因核验，不是新的独立盲测优化成果，未修改生产代码。

`predicted_plus_footprint`把预测掩码中的原始深度点转换到标定世界坐标，并仅保留容器水平轮廓内的点；不读取真实液深或真实液面掩码。`predicted_plus_opening`采用预测掩码与已知容器开口投影的交集。`opening_only`不用网络选点，直接用已标定开口ROI作几何候选区域；增加了已知开口高度和形状条件，并不保证ROI内每个点都是液面。

### 实际失效率边界

原始失效条件396帧中，有155帧真实液面实际失效达到95%–100%，不是本轮后续恢复优化目标。实际75%–90%失效的59帧、90%–95%失效的38帧，在原宽松候选链路中的全帧通过率分别为28.81%和18.42%。这两组是后续锚点归属与时序测试应关注的区间，而不是依据`drop75`或`drop90`名字误把复合失效当成固定失效率。

## 下一轮实验安排

1. 先补齐仿真的干槽实体底面，再以普通液体建立公共选点基线：容器开口ROI、世界坐标轮廓约束和预测掩码一致性；原始可靠深度优先，避免修复网络无条件改写正常点。保留错误层和负候选值用于评估，不以强制液深裁剪改善成绩。
2. 用完整背景数据训练或校准液面掩码，重点加入相似颜色的桌面、容器壁、边缘及错误回波。监督实际液深和误差尾部，不再用相机轴向深度合格替代液位合格。
3. 对正确选点后仍超标的空槽及浅液位，联合液深H与相机距离Z均衡采样，分别验证传感器域系统偏差和少帧现场标定。近距离深液位不应稀释远距离浅液位的错误。
4. 冻结公共方案后生成新的独立普通场景集，比较同帧误差直方图、P95、无解率、1%以内占比及全帧通过率，再决定是否进入眩光或低照专项。当前这批数据随后只能作开发诊断或回归，不能再次声称是未见过的盲测。
5. 漂浮物测试补充不同遮挡比例与物体高度；波动继续同时评估平均、最浅、最深、P05和P95。大面积失效先核验锚点是否真属于液面，再在新的连续序列上评估历史记忆、位姿变化和恢复；本轮静态重复不证明这些时序能力。

95%–100%严重失效保持既定的“不继续恢复优化”边界。额外75%、90%、97%空洞是在已有失效上叠加的故障注入，不等于最终实际失效率；必须使用真实可见表面的实际有效比例分层，不能按注入名称直接排名。背景误选导致的高有值率应作为需要修复的风险，而不是恢复成功。

当前生产配置和安全门控不变，未开展新训练，未替换默认模型，也未重新验证采集至界面的0.5秒端到端延迟。完整代码测试404项通过、14条既有警告。代码测试通过不等于测量精度通过。
