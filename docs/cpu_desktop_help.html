RGBD 液深仿真工作台
CPU 演示版

自带仿真 · V14 测量核心 · 实地部署交互模板

无需另装 Python / CUDA内置仿真器与桌面窗口不需要联网或 USB 相机

本软件在本机生成容器、液面和复杂工况，自动建立空槽与已知液深先验，再运行液深及最高高度测量。它是离线演示与后续部署模板，不是经过工业真机认证的计量设备。

必须保留完整软件目录。不要只复制 EXE；内置运行库、模型、Blender、脚本与许可文件都是必需资源。桌面快捷方式可以指向主程序。

CPU 版本使用 Cycles CPU 仿真，原服务器 EEVEE 性能报告不能直接套用。桌面成品的最终验收状态以随包验收记录为准；源码功能测试不等于 Qt 窗口验收。

01 / 快速启动

  1. 完整解压到本地目录，不在压缩包预览内运行。
  2. 双击主程序 EXE。无需另装 Python、CUDA、Blender 或浏览器，也无需 SSH 连接。首次加载模型可能较慢，请等待。
  3. 等待自动初始化：默认生成空槽图像、建立初始化几何与所需先验，随后完成第一帧测量。
  4. 修改工况后点击“生成并测量”。程序独立运行；内部本机回环通信不需要用户打开网页。

计算使用 CPU，不要求 NVIDIA CUDA 独显。桌面窗口仍需系统显示驱动正常；“无 CUDA”不等于没有任何图形显示依赖。

02 / 界面与操作

左侧：看输入与场景

左键旋转、右键平移、滚轮缩放；“复位视角”恢复观察位置。可独立切换真值、点云、估计液面与相机。

RGB、深度预览均来自本帧生成输入。深度伪彩色图的黑色区域表示无效点。

右侧：设置与测量

“安装与标定”配置容器、相机和先验；“运行工况”修改液深、照明等。真实值和估计值并列显示。

参数改动但未应用时，结果区会明确提示仍显示上一帧。

何时重新标定？

改变安装、材质、光学参数或标定模式时，系统自动重建空槽与先验；只改变液深、光照等运行工况时复用当前安装标定。“重建先验并测量”可显式重新初始化。

默认先验有 ≤10 mm 的高斯标定扰动，并非强求理想标定。当前帧真实液深只在测量后用于展示与评分，不直接提供给测量逆解。

03 / 全部可调参数

安装与标定

参数范围与含义
容器形状圆柱、椭圆柱、矩形。
X / Y 内尺寸各 0.2–6 m。圆柱为内直径，X/Y 自动联动；椭圆为完整轴长；矩形为完整内宽、内长。
容器内高度0.1–9.8 m；液深和波幅均不能使液面越过容器口。
相机到底面距离候选输入 0.2–10 m；实际必须高出容器口至少 0.1 m。自动构图可能上移相机。
顶部偏心 X / Y各不超过对应半径/半宽的 25%，相机保持竖直俯视。
自动构图联动距离与 54°–100° 水平视场，保留完整容器口。无法在 10 m 内构图时提示调整尺寸，不隐藏越界。
先验误差默认固定 10 mm 高斯误差；可切换理想标定诊断。零均值、截断前 σ≈3.33 mm，超过 ±10 mm 的噪声重抽，不裁剪输出。

运行工况

参数范围与含义
液体类型普通漫反射、均匀透明、均匀半透明；初始化时由操作人员确认。
实际液深0–9 m，不高于容器内高度。0.10–9 m 为正式测试范围；低于 0.10 m、包括空槽，仅作诊断。
环境光 / 眩光光照 2%–100%，眩光 0%–100%。这是仿真控制强度，不是实测 lux。
漂浮物0–24 个；形态和位置由内置场景构造器生成。
液面起伏0–120 mm，同时不超过液深的 30% 或剩余容器高度的 50%。
深度缺失控制设定 0%–50%；不等于最终本帧实测液面缺失率。

透明类光学参数

安装页折叠区提供：折射率 1.31–1.45、表面回波权重 0.03–0.12；半透明另提供消光系数 0.02–0.08 /m、散射强度 0.08–0.25。清透明不使用半透明散射设置。

这些是仿真物性，不直接交给测量逆解；改变后重新生成独立 5 帧先验进行辨识。

界面可输入不等于已经全面测试。已发布报告的实际相机到底面样本约 3.532–9.999 m、X 半径/半宽 0.3–1.5 m、Y/X 比 0.65–1.45；超出已发布采样范围会标为探索，不承诺相同通过率。

04 / 功能边界与跳过条件

  • 普通液体可组合已经接入的低照、眩光、起伏、漂浮物、部分深度缺失模块。
  • 透明/半透明仅开放均匀、平整、无遮挡液体；不开放漂浮物或起伏组合。透明类与光照/缺失联合设置为探索配置。
  • 视觉模型仅在需要时参与漂浮物最高高度估计，不替换液深几何核心；最高高度仍有尾部误差和漏检风险。
  • 缺失超过 50%、液面或漂浮物有效支撑不足、相位证据不足等输入会跳过；不执行分类与测量，也不计入性能统计。
  • 仿真资格检查依据独立可见性标签，不能用估计误差大小反过来筛选测试帧。真实部署需要另行接入真实可观测性审查。

当前不含相机 SDK、泵阀、PLC、多传感器安全联锁或工业认证，不能用于安全联锁。

05 / 结果、误差与 CPU 时延

高度统一相对于容器内底面，不是相机到液面距离。代表液面高度与最高高度分开；无漂浮物和起伏时，最高高度不适用。结果不强制归零、不裁剪。

普通液深容差为 max(20 mm, 2% 实际液深)；起伏液面与最高高度为 max(50 mm, 5% 对应实际高度)。分类评分不是计量置信度，“本帧容差内”不是现场精度认证。

以下功能检查使用 Intel Core Ultra 9 285K（24 核）；普通低配电脑可能明显更慢。

阶段12 个 CPU 功能冒烟用例的观察
测量计算约 34–774 ms；已有超过 0.5 s 的尾部用例。
仿真采集约 2–2.6 s；不计入算法推理时间。
复用标定时总耗时约 3 s。
包含重标定约 5–7 s；首次模型加载可能额外增加等待。

界面分别显示初始化、仿真采集和测量计算。以上只是 12 个用例的功能/迁移检查，不是完整性能认证或最大耗时保证；CPU 型号、系统负载、首次加载和工况会改变时延。

Cycles CPU 与原 EEVEE 的 RGB 光照、材质和渲染表现可能不同。即使算法与权重来源相同，原 EEVEE 数据的误差、通过率和 GPU 延时不能直接套用。CPU 渲染链路和 Qt 桌面交互仍需各自验证。

06 / 保存记录与排查问题

“文件”菜单可导出当前测量 JSON，也可打开本次数据与日志目录。默认位置：

%LOCALAPPDATA%\LiquidDepthSimulation

各 session-日期时间 目录保存 desktop.log、标定、输入图像/深度与结果；不会回写只读软件资源。数据会占用磁盘，需在退出后按明确会话目录归档或清理。

现象处理建议
找不到仿真器/模型确认已完整解压并保留资源目录，不是仅复制 EXE。
启动或采集慢等待状态更新，查看日志；不要连续启动多个实例争抢 CPU。
安装或液深冲突修正尺寸、相机、液深和波幅，不绕过校验。
输入不合格查看资格原因、降低遮挡/缺失或调整构图。“跳过”不是深度为零。
窗口加载或运行异常保存本次日志与测量 JSON；检查正常显示驱动。最终 Qt 验收以随包记录为准。

07 / 后续实地部署与资源许可

真实部署需将仿真输入适配层替换为真实 ToF 采集及标定流程，保留模块边界、输入资格检查、结果记录，并完成真实场景精度、长时间稳定性和安全验证。

Blender、Qt、PyTorch 等第三方许可与通知随包附带，复制、迁移和再分发时应保留。当前软件是仿真模板，不替代现场验收。
