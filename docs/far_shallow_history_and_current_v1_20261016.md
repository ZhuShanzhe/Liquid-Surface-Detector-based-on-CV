# 远距浅液位的不足 修复历史与确定版处理方式

2026年10月16日。本版先固定全场景代码和V8漂浮物最高高度模块，后续仅研究远距浅液位。本记录区分已经运行的当前方法、仍保留但未启用的历史实验和下一阶段的待验证问题，不把不同分辨率、噪声、先验和容差下的成绩直接拼接。

## 距离与误差的定义

液深H为液面到容器内底面的竖直高度，相机到底面距离B和相机到液面距离D都不是H。平整近竖直安装时H近似B−D，液深很小时，两个大距离的差对公共偏置、底面法向和先验标注误差都敏感。不能用测距误差除以B得到一个很小百分比，冒充液深相对误差。

本版统一统计`B≥6m、0<H≤1m`，另列`B≥6m、H=0`。较早研究有D≥3m且H<1m、D≥5.5m、B≥6m且H≤0.5m等定义；下表保留各自定义，不混合分母。所有“真实液深区间”仅作离线分组，运行时不能读真值选择方法。

当前主容差为`max(20mm,2%H)`，最高高度为`max(50mm,5%最高高度)`。历史5mm/2%通过率若未经逐帧重算，不改标签冒充20mm标准。MAE、P95等毫米误差仍可描述各自数据，但不同先验难度下不能直接相减当作升级收益。空槽不定义相对误差，毫米级误差在几毫米H下仍可能有很大的相对误差。

## 当前仍存在的主要问题

1. 双目/结构光远端视差小，深度误差随距离的平方放大。以历史320×180代理f约314px、基线35mm为例，10m附近1/16px的视差格对应约0.57m的局部深度间隔。该数值是局部一阶敏感度示例，不是最终液深误差或真实相机规格；实际1280×800、100mm基线档案不可沿用这一格距。
2. 空槽、厘米级液面、底部错误返回的分布会重叠。选到最接近零的峰不等于识别了空槽，选到较高峰也不等于识别了液面。历史V64曾在空槽输出22–134mm，V63曾把约28–43mm真液深解释为约−10至−11mm的底部层。
3. 真实液面返回多不代表每点已经精确。V40受控普通测试中，液面原生返回中位数20544点，通常/较差噪声下原始点到真平面残差中位数74.40/148.20mm；去噪降到7.09/65.01mm，但共同偏移不能靠点数平均消掉。该实验的来源标签只用于事后解释，不进入测量。
4. 邻近像素、同一空槽参考和相邻帧可能共享误差。像素加密、超分和4帧平均都不能把共享偏置变成独立证据。空槽空间噪声变化、底面法向偏差和错误回波混入会留下残差。
5. 当前冻结对称候选采用5–50mm的自适应直方图步长、噪声尺度窗口与空间支持评分；远端较大的σ会使底面/液面证据混合。底面与液面已平等竞争，但评分本身不保证选中物理液面；原始来源正确的点也可能有较大米制偏差。
6. 空槽几何、ROI与尺度先验可能在测量前就不充分。与液面选层失败应分开，不能靠放宽液面门槛修复一个错位的容器坐标系。本轮只审计，不更换不合格先验来提高成绩。
7. 漂浮物最高高度还依赖最高实例是否进入候选。V8最新双目12帧超标复查：6帧无符合真实最高实例的候选、3帧候选全部被拒、3帧已有合格候选仍输出不准。它是最高高度问题，不应全部算到液深或相机没有返回点上。

## 现在对远距浅液位的实际处理

普通、部分失效、低照、眩光、不平整和漂浮物的液深均先用操作员给出的空槽和小规模独立米制信息建立容器坐标；收集ROI内有限正深度，按传感器噪声代理构造候选，底面与液面同规则评分，取稳健候选高度。无候选时沿用原`FormalSceneMeter`回退。支持不足和候选竞争标记保留，但不是对真值误差的硬保证，也不靠关闭输出提高通过率。

没有自动启动四帧降噪、空槽公共偏置联合拟合、V72量化修正或新的弹性真值窗口。旧普通/部分失效方法仍在内部代码中，不等于当前主输出一定采用这些方法。当前噪声仍包括通用双目/结构光代理，不能把它说成已按主流10m相机完成实测参数标定。

透明和半透明不要求液面点云可拟合，采用1组空槽加4组已知液深左右目图像。先验之间多参考配准形成单调响应，未知帧分别匹配左右目先验后软鲁棒融合。半透明使用原生图像的对称加密配准。建议标定覆盖实际可达液深，但代码不以固定百分比强制替代操作员选定值。底纹消失、持续移动或多界面混合不在这条模型的保证范围。

浮物最高高度只按操作者开关运行V8；不足时沿用其选定的回退。V8本身无跨测量帧记忆，不把重复小区域出现当成确认过的最高物体。液深不因视觉开关改变。

所有场景保留负液深、容量外预测、竞争标记和未输出原因。10m附近原始值正常参与原有处理，不新增截断；10m应用布置和默认10.5m原始返回档案分开记录。相机移动或初始化失效应重新标定，不以历史液深硬平移掩盖。

## 下一阶段工作约束

后续只针对远距浅液位：先核验容器内真实表面证据、候选召回/误拒/裁决、公共偏差和量化模型，再比较参考差分及静止多帧是否提供可重复收益。先验错误、真实点有噪声、错物理层必须分开统计，不因事后看到真值能找点就声称运行时可辨识。

以本确定版建立配对对照；新方案在新的安装级验证集上选型，再用独立容器/位姿/噪声检验。空槽、0–0.1m、0.1–0.5m、0.5–1m分别统计，按B、D、传感器、丢失率和有效独立空间块分层；其他液深和场景只作防回退。几毫米差异单独说明，不以通过率变化替代误差分布。

当前尚未实施上述新优化。本轮不修小浮物、一般眩光/低照、一般波面、多层透明或95%–100%失效。置信度仅作诊断，不为凑覆盖率或通过率强制归零、裁剪或删除失败帧。
