# 现场少样本标定与顶部相机部署

## 1. 为什么不能只用现场几张图训练

系统采用“通用模型 + 现场少样本标定”两层结构。通用模型在公开数据和仿真数据上学习透明、半透明、强反光、低照度、错误回波与深度空洞；现场样本只用于估计当前相机、容器和安装位置造成的尺度与偏置，不重新训练整个网络。这样既避免少量现场数据过拟合，也保留跨容器和跨液体的能力。

## 2. 顶部安装约束

生产相机应安装在容器上方。仿真训练的主要相机仰角为 60°–87°（90°为正上方垂直俯视），保留少量 42°–60°样本用于安装误差和遮挡压力测试，并使用 72°–88.5°独立近垂直测试集。相机、容器或镜头明显移动后，原标定不再有效。

## 3. 推荐采集方案

- 选择 5–8 个已知液深，至少覆盖预计工作量程的低端、中部和高端。
- 每个液位静置后采 3–5 帧，不要把相邻视频帧当成独立液位。
- CSV 可使用 `level_id` 合并同一液位的多帧并取中位数，使用 `role=validation` 将该液位保留为不参与拟合的验收集。
- 至少 3 个液位用于拟合，另保留至少 2 个液位只做验收；推荐 5 个拟合液位和 2–3 个验收液位。
- 标定液位的总跨度不得小于 20 mm，且不应集中在量程的一小段。
- 标定与验收必须保持同一相机分辨率、焦距、安装位置、容器位置和深度单位。
- 同一液位多帧先取稳健中位数；漂浮物、气泡或晃动明显的帧应标记而不是强行作为真值。

## 4. 软件计算流程

1. 通用模型从 RGB-D 帧预测液面掩码、米制深度、法向和不确定度。
2. 在高置信液面内部采样并拟合平面，弯月面和容器边缘单独处理。
3. 用多帧稳健统计得到每个标定液位的原始预测。
4. calibrate-output 使用稳健仿射模型：实际液深 = scale × 原始预测 + offset。
5. 报告拟合误差和留一交叉验证误差；少于 5 个有效样本时明确标记为样本不足。
6. 用未参与拟合的液位验收。验收不合格时，不应通过继续拟合验收样本来掩盖问题。
7. 日常测量执行不确定度、空间支持、物理一致性和时序门控；失败帧被拒绝，可提供短时预测值用于诊断，但不作为新的有效测量。

## 5. 验收标准

按项目工业精度档案，单次误差目标为 max(3 mm, 真实液深的 1%)。几十厘米量程主要受 3 mm 绝对误差下限约束；数米量程以约 1% 相对误差为主要目标。报告必须同时给出 MAE、RMSE、最大绝对误差、AbsRel、达标率和有效输出覆盖率。不能只报告被模型接受样本的误差而省略拒绝率。

## 6. 何时需要重新标定或微调

仅固定尺度/偏置变化时，重新现场标定即可；更换相机型号、容器形状、液体光学性质或照明后出现系统性识别失败时，才需要加入少量真实标注做模型微调。若持续移动相机，则应提供容器 CAD 和实时位姿来源，固定机位少样本标定不能代替几何定位。
