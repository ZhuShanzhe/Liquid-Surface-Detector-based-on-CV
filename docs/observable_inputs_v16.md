# V16：现场可获得输入与获取链路

## 允许进入模型的信息

| 信息 | 获取方式 | 本轮实现 |
|---|---|---|
| 彩色图 | RGB-D 相机的彩色帧 | 输入整幅图像，缩放到 320×180 |
| 原始深度 | 相机深度帧，保留失效点 | 按明确的单位换算成米，不根据液面猜单位 |
| 深度单位 | 相机 SDK 的 depth scale 或采集文件说明 | camera.json 的 depth_scale_to_m 为必填 |
| 彩色与深度对齐关系 | SDK 输出的已对齐深度；或出厂标定 | 已对齐模式检查尺寸；原生模式使用标定重投影 |
| 液面区域 | 从当前 RGB-D 预测 | 重新训练定位模块；不接收真值掩码 |
| 单深度先验 | 定位模块从同一 RGB-D 预测 | 内部估计量，不需要用户填写 |
| 可用测量点和归一化范围 | 从预测区域及原始有效深度计算 | 少于 32 点时，区域筛选路线返回无有效深度 |

**没有进入模型：**材料类别、液面真值、液深、底高、容器尺寸、世界坐标相机位姿、相机到液面的真实距离、仿真误差倍率、真值法向。

本轮逐像素深度恢复不需要相机内参。只有未对齐输入的注册步骤使用出厂内参及深度相机到彩色相机的外参。这里的外参是设备内部两路相机之间的标定，不是相机相对容器的位姿。

## 采集文件约定

已由 SDK 对齐到彩色图坐标的深度：

```json
{
  "depth_scale_to_m": 0.001,
  "depth_alignment": "color"
}
```

0.001 仅表示示例文件的每个深度单位为 1 mm。必须使用实际设备给出的换算比例，不能照抄。仅凭图像尺寸一致不能验证几何对齐；采集端须确认 SDK 的对齐设置。

若深度仍在原生深度相机坐标系，使用 depth_alignment="native"，并从 SDK/出厂标定导出：

- depth_camera_matrix、color_camera_matrix：3×3 内参；
- depth_resolution、color_resolution：[宽, 高]，与采集分辨率一致；
- depth_to_color_rotation：3×3 旋转；
- depth_to_color_translation_m：以米表示的三维平移；
- depth_distortion、color_distortion：OpenCV 针孔/Brown 模型的畸变系数，无畸变时为零。

注册步骤反投影深度、转换到彩色相机坐标系、投影到彩色图；多个点落到同一像素时保留较近的彩色相机轴向深度。没有观测的像素保留为零。鱼眼或其他畸变模型须先由相机 SDK 转换，不能直接套用此针孔实现。

缺少单位或标定时会报错，不从液面真值估算这些参数。当前没有连接真实相机，SDK 自动导出适配仍取决于设备型号；文件接口和注册算法已实现并测试。

## 推理入口

```bash
PYTHONPATH=src python scripts/predict_observable_v16.py \
  --rgb /path/rgb.png \
  --raw-depth /path/raw_depth.npy \
  --camera-json /path/camera.json \
  --weights /root/autodl-tmp/liquid-depth-artifacts/training/observable-v16-20260916 \
  --route gated \
  --transcg-source /root/autodl-tmp/liquid-depth-data/research/sources/TransCG \
  --output /path/new-output-directory
```

输出 depth_m.npy、mask_probability.npy、masked_depth_m.npy 和 status.json。mask_probability 只描述液面区域，**不是深度正确概率**。本轮未获得可部署的深度置信度，输出均属于研究结果。

运行时只加载 RGB、原始深度、采集配置和模型权重；不加载训练清单、液面标签或场景仿真元数据。模型的 0.1–10 m 数值范围不代表任何相机在全范围内均能可靠测量。

## 最终液深还缺哪一步

本轮不输出底面参考的液深。若要转换成液深，需要另行获取：

1. 相机内参与单位：来自设备标定。
2. 底面参考：固定安装后采集空容器；若透明底面不能可靠测量，使用可移除的不透明标定板或独立量具，并记录板厚/参考偏置的实测值。
3. 相机与容器相对关系：固定机位标定；移动机位需要在线跟踪可识别的标定目标。
4. 液面重建有效性：检查可靠点是否足够、空间是否分散，不能只检查平整程度。
5. 独立液深对照：使用量具或其他独立方式测量，不能用同一模型输出作为真值。

这些获取步骤尚未在现场完成，本轮没有把底高、液深或标定位姿作为已知输入加入实验。

## 仿真与现场的边界

完整场景深度由生成 RGB 时相同的环境、容器和随机种子进行离线光线求交，再加入噪声、玻璃回波近似、缺失和量化。场景几何用于生成训练观测和标签；**推理没有读取几何参数**。

这比液面之外全零的输入更接近完整相机帧，但仍不是真实相机的光学/传感器仿真。背景材料、深度缺失模式和容器布局还可能形成仿真特有线索，必须用现场数据复验。

单帧 RGB-D 本身也不保证能识别整体尺度偏差：如果原始深度整体偏大，且缺少独立的实际尺寸参考，不能声称算法总能自动恢复绝对尺度。本轮不会提供由仿真真值计算出的校正倍率。
