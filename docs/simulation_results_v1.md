# 液面深度通用模型：仿真与混合训练阶段结果

更新时间：2026-08-28

## 1. 阶段目标

本阶段建立不依赖单一公开数据集的透明/半透明液体仿真与训练闭环，用于覆盖普通、透明、半透明、强反光、低照度、深度大面积失效、多层透明、液面不平、漂浮物和复合退化场景。深度范围按对数均匀方式覆盖 0.1–10 m；分量程指标仅用于诊断，不限制模型量程。

模型同时预测液面掩码、米制深度、法向和不确定度。严格容差定义为逐像素误差不超过 `max(真实深度的 1%, 3 mm)`。

## 2. 已生成数据

- Eevee 试验集：2,000 帧，10 类场景各 200 帧，训练/验证/测试为 1,576/208/216。
- Cycles/OptiX 高保真子集：200 帧，10 类场景各 20 帧，训练/验证/测试为 156/20/24。
- 混合训练清单：9,284 条，包含项目仿真、ClearGrasp Synthetic、TODD 和 TransCG；独立测试集不进入训练。

## 3. 模型结果

### 3.1 纯仿真初始化（32 基础通道）

在 Eevee 独立测试集上：MAE 195.8 mm、RMSE 452.4 mm、AbsRel 12.25%、严格容差通过率 11.77%。该模型仅证明训练链路可运行，不应作为真实工业部署权重。

### 3.2 纯仿真后混合微调（32 基础通道）

- ClearGrasp Real：MAE 53.9 mm、RMSE 71.8 mm、AbsRel 9.89%。
- DREDS STD 抽样测试：MAE 48.5 mm、RMSE 75.0 mm、AbsRel 7.30%。
- 项目仿真测试：MAE 152.3 mm、RMSE 460.6 mm；推理延时约 3.4 ms/帧。

### 3.3 v2 真实域权重初始化后混合微调（24 基础通道）

- 混合验证集：MAE 41.6 mm、RMSE 205.2 mm、AbsRel 5.24%、严格容差通过率 20.47%、掩码 IoU 0.693。
- ClearGrasp Real：MAE 30.1 mm、RMSE 43.7 mm、AbsRel 5.82%、严格容差通过率 13.11%。
- DREDS STD 抽样测试：MAE 49.0 mm、RMSE 75.1 mm、AbsRel 7.37%。
- 项目仿真测试：MAE 125.7 mm、RMSE 346.5 mm、严格容差通过率 24.18%；推理延时约 3.2 ms/帧。

按项目仿真场景拆分，透明、半透明、多层透明、不平液面和漂浮物的 AbsRel 分别约 3.09%、3.26%、4.14%、2.65% 和 2.27%；强反光约 4.62%。深度大面积失效场景仍明显最弱，不能视为已解决。

### 3.4 加入 200 帧 Cycles/OptiX 后短微调（当前推荐通用实验权重）

- Cycles 独立测试：MAE 115.6 mm、RMSE 393.6 mm、AbsRel 7.46%、严格容差通过率 12.32%；微调前分别为 151.8 mm、501.1 mm、11.30% 和 11.20%。
- Eevee 项目仿真测试：MAE 120.4 mm、RMSE 318.2 mm、AbsRel 19.08%、严格容差通过率 24.67%。
- ClearGrasp Real：MAE 30.3 mm、RMSE 43.7 mm、AbsRel 5.86%，与微调前基本持平。
- DREDS STD 抽样测试：MAE 47.6 mm、RMSE 75.5 mm、AbsRel 7.12%，较微调前小幅改善。

高保真子集改善了高保真仿真域和 DREDS，同时未造成明显真实域灾难性遗忘；但样本量仍小，不能据此宣称达到工业精度。

## 4. 结论与权重使用规则

仿真训练能够扩展复杂场景覆盖，并显著缩小纯仿真到真实数据的域差距，但当前通用模型尚未达到项目目标的约 1% 误差，也未全面超过原 v2 或论文专用基线。当前部署应继续以原 v2/专用恢复模型为稳定主路径，将 Cycles 微调通用模型作为可选复杂场景实验分支；只有通过目标相机、目标容器和目标量程的验收数据后才能晋升为默认模型。

网络前向延时远低于 0.5 s 预算，后续可以把算力主要用于更好的传感器退化模拟、模型路由、时序滤波和几何拟合，而不必优先压缩网络。

## 5. 下一轮优先级

1. 用目标 RGB-D 相机采集少量空容器、普通液体、透明/半透明液体、强反光和深度失效片段，估计真实传感器的空洞形态、错误回波和距离相关噪声。
2. 用 Cycles/OptiX 高保真样本与真实噪声统计校准仿真器，而不是盲目扩大同分布 Eevee 数据量。
3. 对深度大面积失效单独提高采样权重，并加入 RGB 单目先验、边缘连续性、不确定度拒绝和时序恢复；失效面积比例应作为路由条件。
4. 保留原 v2 稳定路径与通用复杂场景路径，基于置信度和退化分类动态选择，最终液深仍由可靠液面点的鲁棒平面/局部曲面拟合输出。
5. 以真实工业验收集报告分量程 MAE、AbsRel、1%/3 mm 通过率、液深误差、拒绝率和端到端 P95 延时。
