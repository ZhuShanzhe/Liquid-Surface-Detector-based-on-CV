视觉辅助模块选路优化研究记录
==========================

日期：2026-10-20。本记录不是新的正式测量性能报告。

结论与版本状态
--------------

ToF最高高度增强formal v3已独立验证并合并，提交f668bdee942e804d9f613a335f431b0d907040e0。
该次1000帧测量对照的新旧液深逐帧完全相同，最高高度误差改善；本记录只研究其后的视觉分类选路。

新选路候选已训练与独立测试，但没有覆盖正式分类头，也没有改变正式液深、最高高度或透明相位数值链路。
正式默认仍使用原场景分类头；新增最高高度专用存在性探测可独立弥补部分漏启用。
新分类候选的完整四开关组合准确率88.56%，单开关平均97.00%。接近90%，但不能称严格90%已经达标。
漂浮物精确率92.81%、召回率88.17%；预声明门槛还要求完整组合及漂浮物精确率/召回率均≥90%，未通过。
因此遵守“效果不好不合并正式版”，保留研究模型与全部记录，不做默认接入；未用现场计量或传感器资格作背书。

评价对象与应用边界
------------------

四个学习开关为低照观察审计、眩光观察审计、不平整包络建议和漂浮物最高高度视觉建议。
完整组合准确率要求同帧四个开关全部正确；单开关平均正确率不能替代它。
标签由仿真工况因素是否存在构建，属于选路代理任务，不等价于“启用该模块一定提升测量”。
故正式推广还必须做端到端测量非退化验证，本轮在准确率门槛失败后没有冒充已完成这一步。

只评估已确认普通漫反射材质的ToF、固定安装和既有复合因素。透明/半透明仍由物理初始化确认，
使用已有五帧原始AMCW相位先验；RGB材质分辨准确率未因本轮变成90%。
部分深度缺失按观测到的标定容器ROI有效性进行确定性审计，不从RGB猜测，也不混入学习准确率抬高数字。
不对强散射、多层透明、移动相机或95%–100%严重深度失效新增适配承诺。
分类统计保留全部1600帧，不因预测错误、微小目标或证据弱删除。测量场景的原始输入质量规则没有被放宽。

训练与独立性
------------

第一轮：既有4200帧转为开发数据，20个新安装/320帧作验证，100个新安装/1600帧独立测试。
第二轮：增加空间连续性与原生RGB局部信息，使用另一套100安装/1600帧新测试；第一套不再叫新独立集。
第三轮：再新增64安装×32条件=2048开发帧，总开发6248帧，验证仍320帧；
重新生成100安装/1600帧第三套独立测试，种子202610211231，测试安装offset120000。
旧独立研究数据在本轮转作开发数据的事实已明确披露，不能重复声称它们是本轮独立测试。
每轮模型、阈值只由开发与验证选定，冻结后才计算新测试成绩，不在同一测试集上反复调门槛。
第三轮训练覆盖五因素的32组合，独立测试为16种既有组合各100帧；不等于32组合或实际工业全域均已验证。
同安装不同工况相关；本报告按100个安装聚类，自助法3000次计算完整组合准确率区间。

可部署输入只有当前RGB-D、空槽图、标定容器几何与原始有效性；当前真值、语义或回波来源标签不进入特征。
标签只在推理后用于统计与诊断。前两轮完整原始报告保留，后续模型未利用第三套测试标签调参。

方法
----

1. 保留原MobileNet视觉特征与RGB-D几何特征，另复用最高高度分支的高分辨率语义/可靠回波特征。
2. 增加稳健低频空间起伏拟合、局部颜色与深度异常、连通支撑等信息，区分波面与随机噪声。
3. 原生RGB开口投影不受当前深度有效性限制，深度空洞时仍能提出图像中可见的小漂浮物证据。
   这只能帮助识别，不为最高高度凭空产生可用的测距点。
4. 增加32种工况组合的均衡开发样本，补足此前缺少眩光+起伏+漂浮物组合的问题。
5. ExtraTrees与逐开关梯度提升头在验证集比较；最终选HGB。阈值目标同时考虑完整组合、宏F1及漂浮物精确率/召回率。
   置信概率不是米制测量置信度，分类不能取消最高高度的真实回波空间支撑检查。

起伏漏报中15/27帧设定振幅小于近似3倍ToF单点噪声，存在可观测性限制；并非所有漏报均属于硬件无信息。
局部小物体信息经全局池化、统计汇总后仍可能被背景稀释；波面、高光边缘、容器边缘产生相似局部异常，
以及复合条件间的分布差异，仍会导致漏报/误报。没有将这些帧简单剔除以得到90%。
四个开关各自有少量错误，叠加后完整组合正确率必然低于单开关平均；97%单开关不等于97%组合。

下一步建议为原生局部小目标分类/多实例分支与高光/波面硬负例，而不是继续堆全局统计或盲目降低阈值。
仍用新的安装级独立集验收，并同时评估实际模块启用后的测量误差；未达标不替换默认头。
