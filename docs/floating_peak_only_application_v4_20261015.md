# 漂浮物最高高度视觉辅助的应用边界与验证结果

实验批次：2026-10-15。本次只收紧应用入口并回放验证，不重新训练模型，不生成新的独立测试集。

当前视觉模型仅用于明确选择的漂浮物场景，且只辅助相对容器底面的最高高度。液面高度即底面参考液深始终由原几何链路给出。普通、低照、眩光、不平整、部分深度失效、透明和半透明场景均禁止使用这套视觉辅助，不再沿用旧报告中针对这些场景的可选启用建议。

## 应用边界

| 项目 | 当前规定 |
| --- | --- |
| 允许的主场景 | `floating_objects`，已验证的普通/不透明漫反射液体表面有可见固体漂浮物 |
| 启用条件 | 操作员或安装配置明确选择漂浮物场景，并显式开启最高高度视觉开关 |
| 允许修改的输出 | `highest_height_m`，包含漂浮物的最高高度，相对容器底面 |
| 禁止修改的输出 | `liquid_depth_m`、液深是否有数值、液深来源与原有几何诊断 |
| 标定与输入 | 匹配的空槽几何/深度参考、米制标定、对齐RGB-D；固定顶视安装或移动后重新标定 |
| 没有可靠漂浮物候选 | 保留原几何最高高度，液深不因视觉候选被拒绝而取消输出 |
| 默认状态 | 视觉关闭，只有显式开启且场景符合时才加载、执行模型 |
| 其他场景误开开关 | 不加载、不调用模型，保留该旧场景路径，并返回禁用原因 |

不将透明液体加漂浮物、严重低照/眩光加漂浮物、严重深度失效加漂浮物等复合场景重新标为普通漂浮物场景以绕过边界。透明/半透明仍走独立五帧先验折射路径。本模型内部保留语义和回波来源多头，用于辨别浮物证据，不用视觉液面头改写液深。

场景类别由调用方明确传入，不是模型自动判断的结果。模型无法事先保证每帧确实存在漂浮物；没有检测到可靠浮物时执行几何回退，不能用测试真值来决定运行时是否开启。

## 代码约束与部署入口

- 选定配置：`configs/application_route.json`。
- 应用类：`liquid_depth.floating_peak_only_v4.FloatingPeakOnlyMeter`。
- 模型配置：`configs/floating_peak_only_v4.json`。
- 命令入口：`scripts/measure_floating_peak_v4.py`。

应用类先执行关闭视觉的旧链路，仅在允许的场景下调用浮物辅助，并只复制最高高度字段。即使辅助模型错误地返回另一液深或改变数值有效性，也不会覆盖旧液深输出。模型按需加载；已加载的权重可缓存，但切换到其他场景后不再执行它。

旧V2/V3实验接口和封存记录保留用于复现，不作为当前部署入口。此前报告推荐低照、眩光、部分丢失试用视觉的表述已被本边界替代；不修改历史实验源码和数据来伪装成当前配置。

```bash
cd /root/autodl-tmp/Liquid-Surface-Detector-based-on-CV
export PYTHONPATH=src:scripts
/root/autodl-tmp/envs/liquid-depth/bin/python scripts/measure_floating_peak_v4.py \
  --scene floating_objects --enable-floating-peak-vision \
  --bundle /path/to/calibration.json --dry /path/to/dry_depth_m.npy \
  --depth /path/to/current_depth_m.npy --rgb /path/to/current_rgb.png
```

不启用视觉时省略 `--enable-floating-peak-vision`。其他主场景即使传入这个开关也会忽略视觉请求。透明/半透明通过API保留已有折射路由，不通过本RGB-D回放命令替代其输入接口。

## 回放与边界核验

复用上一轮独立仿真集，种子 `202610155927`，不再调整像素权重、区域分类器、偏置修正或阈值。396帧全部通过新应用入口，均故意提出视觉请求，以验证场景限制，而不是只测试正常开关操作。

- 漂浮物类别66帧，其中60帧有可见漂浮物，6帧为空槽控制。
- 另外五类330帧：模型执行次数为0、最高高度相对旧几何变化帧数为0。
- 全396帧：液深相对旧几何变化帧数为0。
- 漂浮物类别最高高度与上一版V3差异超过1微米的帧数为0，收紧入口没有改变其浮物估计算法。
- 透明/半透明的禁用与输入转发由单元测试核验，本次没有重新测试其折射测量精度。

主统计采用真正有可见漂浮物的60帧，不混入更容易通过的空槽控制。是否有可见浮物的真值仅在测量完成后用于报告分组，不参与启用、候选选择或测量。每个安装有两次深度采样，同一安装的帧不是完全独立样本。

## 有漂浮物时最高高度效果

60帧的容差为 `max(50mm, 5% × 真实最高高度)`，分母为全部60帧。

| 链路 | MAE / mm | P95绝对误差 / mm | 容差通过率 | 数值输出率 |
| --- | ---: | ---: | ---: | ---: |
| 旧几何，无视觉 | 147.24 | 238.30 | 60.00% | 100% |
| 上一版视觉V2 | 61.51 | 204.58 | 80.00% | 100% |
| 当前限域链路 | 40.38 | 128.36 | 85.00% | 100% |

相对旧几何，最高高度MAE降低约72.6%，通过率提高25个百分点；相对旧视觉V2，MAE降低约34.4%，通过率提高5个百分点。本次入口限制本身不带来额外精度收益，精度来自原V3浮物模块，限制的作用是阻止它影响其他场景或液深。

### 最高高度绝对误差占比

| 链路 | <20mm | 20–50mm | 50–100mm | ≥100mm |
| --- | ---: | ---: | ---: | ---: |
| 旧几何 | 0.00% | 10.00% | 15.00% | 75.00% |
| 旧视觉V2 | 36.67% | 16.67% | 28.33% | 18.33% |
| 当前限域链路 | 50.00% | 16.67% | 25.00% | 8.33% |

当前仍有5/60帧绝对误差≥100mm，9/60帧没有满足最高高度容差。相对真实最高高度的误差占比：<2%为70.00%，2–5%为15.00%，5–10%为1.67%，≥10%为13.33%。最高高度的相对误差不以相机距离或液面液深为分母。

## 有漂浮物时液面液深效果

液深相对真实底面，容差为 `max(20mm, 2% × 真实液深)`。

| 链路 | MAE / mm | P95绝对误差 / mm | 容差通过率 | 数值输出率 |
| --- | ---: | ---: | ---: | ---: |
| 旧几何 | 18.25 | 73.98 | 93.33% | 100% |
| 当前限域链路 | 18.25 | 73.98 | 93.33% | 100% |

液深逐帧一致，变化0帧。当前液深绝对误差<20mm占83.33%，20–50mm占5.00%，50–100mm占8.33%，≥100mm占3.33%；相对液深误差<2%占83.33%，2–5%占6.67%，5–10%占3.33%，≥10%占6.67%。数值输出率100%不代表所有帧测量合格。

## 控制组与版本兼容统计

6个空槽控制帧未接纳浮物视觉证据。液深MAE2.93mm、P956.60mm，最高高度MAE6.13mm、P959.06mm；两个容差通过率均100%，结果与几何对照相同。

若为对照旧报告而合并60个浮物帧和6个空槽帧，总66帧最高高度MAE37.26mm、P95120.25mm、通过率86.36%；液深MAE16.86mm、P9570.76mm、通过率93.94%。这些数值与旧报告一致，但本次应用结论优先使用60帧真实浮物统计。
