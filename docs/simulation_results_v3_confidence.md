# V6 场景置信度与大面积深度失效仿真结果

更新时间：2026-09-04

## 1. 本阶段结论

V6 已完成面向顶部安装 RGB-D 相机的 12,000 帧多样化仿真、置信度专训、场景均衡联合微调、独立测试、分场景阈值校准和 TorchScript 导出。模型覆盖 0.1–10 m，不按量程拆成互不兼容的模型；量程分段只用于诊断。

本阶段采用 max(5 mm, 2%) 作为置信度监督和仿真资格判定容差，不把 1% 作为固定死线。软件著作权登记本身没有精度门槛；这里的指标用于工程质量控制，不能替代目标相机的现场计量验收。

从 2026-09-04 起，项目采用两级门槛：现有 AbsRel≤3% / 容差通过率≥50% / 输出覆盖率≥30% / 可评估输出率≥90% 仅作为“仿真候选准入线”；工程产品线按场景分级，普通场景要求 AbsRel≤1.5%、通过率≥90%、覆盖率≥95%、可评估输出率≥99%，复杂受支持场景要求 AbsRel≤3%、通过率≥75%、覆盖率≥80%、可评估输出率≥98%。多层透明、严重/极端失效和复合退化不强制输出，但错误接受率必须≤1%并给出明确拒绝原因。所有工程验收还必须报告 P95、最大误差、偏差和视频稳定性。

## 2. 数据和训练

正式仿真集共 12,000 帧：

- 训练 9,604 帧、验证 1,200 帧、独立测试 1,196 帧。
- 场景包含 ordinary、transparent、translucent、multilayer、glare、low_light、floating_objects、uneven_surface、depth_failure 和 compound。
- 大面积深度失效和复合退化按观测到的原始有效深度比例分为 partial（≥45%）、large（25%–45%）、severe（10%–25%）和 extreme（<10%）。
- 仿真随机化包含顶部/近顶部视角、容器类型与尺寸、液位、液面扰动、漂浮物、曝光、眩光、透明/半透明材质，以及 active stereo、structured light、ToF 的空洞和错误回波代理。
- 训练使用场景—严重度均衡采样，防止普通样本或极端空洞样本单方面主导梯度。

复现实验入口：

`bash scripts/run_v6_v3_calibration_pipeline.sh`

## 5. 部署边界

- 本报告仅证明仿真域内的改进；`synthetic_only=true`、`hardware_qualified=false`。
- 生产配置继续默认关闭该置信度策略。只有用目标相机完成现场独立验证后，才能开启对应场景路由。
- severe/extreme 深度失效、多层透明以及复合退化仍是后续算法重点；当前应明确拒绝，不应输出最终液深。
- 固定机位推荐 5–8 个已知液位做尺度/偏置标定，并保留至少 2 个液位只做验收。相机或容器明显移动后重新标定；持续移动场景需要 CAD 和实时位姿。
- 工业验收需按量程与场景同时报告 MAE、AbsRel、严格容差通过率、覆盖率、拒绝率、最大误差和端到端 P95 延时。

## 8. 面向未达标项的模型改进

- 普通场景：增加液位尺度/偏置校准头、按量程均衡采样、容差越界损失和 P95/分位数损失，重点压缩尾部误差而非继续追求平均值。
- 透明/半透明：引入透明区域专用编码器、每条视线多层深度候选、层序约束和折射材质随机化；用法向、容器边界、底面与历史液位共同选择液面层。
- 强反光：增加饱和高光显式掩码、曝光/HDR随机化、镜面专家分支和保留有效原始深度的融合策略；高光区域不可观测时提高拒绝概率。
- 低照度：将轻量低照增强与液面网络联合训练，加入光子噪声、颜色偏移、运动模糊和曝光变化；使用时序一致性恢复稳定 RGB 先验。
- 漂浮物：增加漂浮物/泡沫独立分割头，以可靠液面点的空间覆盖和几何一致性加权，避免漂浮物深度污染平面。
- 大面积失效：按位姿或光流传播历史可靠点，增加可靠点记忆、RGB引导补全和不确定度校准；没有尺度锚点时必须拒绝。
- 多层透明：参考 SeeGroup/LayeredDepth 的分组与层状表达，从单深度改为容器壁、液面、底面等 K 层候选，并学习可见性和层序。
- 严重/极端及复合退化：采用场景专家混合、组合增强与难例挖掘；单帧不可观测时依赖时序、第二视角、CAD或其他传感器，不以生成式猜测替代测量。

后续每次训练均应同时给出普通场景无回退检查、复杂场景分路由结果、错误接受率、P95/最大误差和视频稳定性；缺少这些指标时不得宣称达到工程产品线。
