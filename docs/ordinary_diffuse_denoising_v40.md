# 普通漫反射液面去噪与平面校正试验

日期：2026年10月12日。

在相机和容器底面已标定、普通漫反射液面具有充分有效返回点的受控仿真中，视差域去噪能显著减小点云散布，但不能独立消除公共测距偏移。一帧独立空槽观测结合当前帧稳健估计，可以改善液位；复用空槽空间残差还可以改善自由拟合平面的倾角。空槽与测量帧之间的空间噪声变化较大时，远距离浅液位仍明显退化。因此本实现保留为可选研究链路，未替换工业面板默认链路，也不作为硬件精度承诺。

## 普通链路应用边界

普通链路针对在工作波段主要返回液面信号的正常漫反射液体。视觉上颜色浑浊或不透明，不自动等于深度传感器能够获得可靠表面返回；实际还需确认红外返回和匹配质量。

| 条件 | 当前处理边界 |
| --- | --- |
| 相机与标定 | 顶部固定安装，内参、双目基线、重力方向、容器底面和范围已标定；移动后重新标定 |
| 容器 | 竖直凸容器，已知内部底面和开口范围；锥形、弯曲底面及未知容器不在本试验中 |
| 液面 | 水平或近似水平；自由平面仅作倾角诊断，正式液位使用重力约束水平面 |
| 液体光学特性 | 单一表面返回为主；透明折射、半透明体积回波和多层混合回波交给对应专用链路 |
| 波动和遮挡 | 明显波动、漂浮物、大面积失效、强饱和和极端复合情况不由本试验认定已适配 |
| 距离范围 | 测试和后续应用适配限定相机到底面中心距离不超过10 m，液深采样为0至9 m |
| 数值使用 | 不因测量值略高于10 m而删除、置零或裁剪；空槽测量保留正负误差，不做零位吸附 |
| 硬件边界 | SDK已输出无效值、零值或物理无返回时，算法不能把它当作有效测量恢复 |

既有混合回波试验默认加入2%至16%底面错误回波。这是压力条件，不能作为正常漫反射液体的默认现象。本轮普通主测试不加入底面回波；另设2%离散异常点条件验证稳健性。

## 方法与测量定义

液深统一为液面相对容器内部底面的竖直高度，单位为米。真实液深、真实返回标签和真实平面只进入数据生成器与评估器，不进入测量函数。空槽帧的身份由操作人员给出，使用已独立标定的底面作为参照，不利用测试帧真实液深。

新链路在保守容器ROI内腐蚀边界，使用原生分辨率有效深度。先转换为视差，稳健估计平面趋势；对残差进行局部异常点抑制和17像素窗口平滑，再拟合重力约束液位。去噪不填补原始无效点，不跨容器边界扩张有效范围。邻接差分用于估计随机噪声强度。

空槽校正分两级：标量校正消除相同ROI上的公共偏移；空间校正使用空槽残差图，并根据当前帧与空槽残差的相关性确定迁移权重。相关性估计先去掉自由平面趋势，避免把液位或倾斜本身当成可复用噪声。低相关性降低空间校正权重，但不拒绝输出。

试验对比五种处理：既有混合回波算法在放宽数值范围后的基线、无空槽的全像素稳健估计、仅去噪、去噪加空槽标量校正、去噪加空槽空间校正。表中“新方法”指最后一种；标量和空间校正的液位收益接近，空间校正的额外作用主要体现在倾角。

## 仿真与独立测试设置

采用既有Gemini 2 XL主动红外双目档案的1280乘800分辨率、约628.93像素焦距和0.1 m基线。它是主动双目，不是单目相移结构光。噪声沿用视差标准差0.18像素和0.36像素两组假设，后者包含16像素块状空间相关噪声。噪声幅度和块模型是敏感性假设，不是厂商实测标定结果。

主测试使用独立种子202610124207，共320个安装配置、2560帧：128个远距离浅液位配置、24个空槽配置、24个近零液位配置，以及每个1 m液深区间16个配置。每配置包含两组噪声条件和各4帧重复观测。远距离浅液位为液深0.01至1 m，相机到液面距离约5.5至9.7 m；近零液位为5至100 mm。

异常点测试另用160个配置。时变空间噪声测试另用160个配置，在相同安装与基础随机输入上比较0.5和0两种空间噪声相关性。重复帧和配对敏感性条件不是额外独立安装样本；不将它们合并宣称为独立工业场景。

新数值实验取消了原仿真按10 m硬截断带噪深度的步骤。所有方法在同一新观测上对比，旧基线的似然数值范围同步放宽。不能将本表直接与旧的硬截断、含底部回波测试表相减，并把差值全部归因于去噪。旧结果和源代码均保留。

## 液面返回点与平面诊断

普通主测试中，保守ROI内每帧实际来自液面的有效返回点为7014至49138个，中位数20544个，覆盖44至235个16像素空间块。该比例为100%是普通仿真的生成设定，不是实物检测结论。异常点条件下真实液面返回比例中位数约98%。

“来自液面”与“误差已经很小”是两个不同概念。普通主测试逐帧统计后，处于真实平面5 mm以内的点比例中位数仅为通常噪声4.17%、较差噪声2.12%。因此不能仅按一个严格毫米阈值筛点，再把剩余少量点解释为只有少量真实液面返回。

| 诊断指标 | 通常噪声 | 较差噪声 |
| --- | ---: | ---: |
| 原始点到真实平面残差中位数的逐帧中位数 | 74.40 mm | 148.20 mm |
| 仅去噪后同一指标 | 7.09 mm | 65.01 mm |
| 原始稳健自由平面倾角中位数 | 0.093° | 1.734° |
| 空槽空间校正后自由平面倾角中位数 | 0.095° | 0.195° |
| 原始自由平面倾角P95 | 0.366° | 5.777° |
| 校正后自由平面倾角P95 | 0.382° | 0.769° |

单点残差不是最终液位误差。多数点包含大幅随机噪声但仍围绕同一液面提供证据；估计大量点可以降低随机项，无法降低所有点共同携带的偏移。通常噪声下自由平面倾角略有变化，不构成有意义改善；不能声称所有指标均提高。

## 去噪与空槽校正的消融

| 远距离浅液位处理 | 通常MAE | 较差MAE |
| --- | ---: | ---: |
| 无空槽的全像素稳健估计 | 11.477 mm | 27.492 mm |
| 仅局部去噪 | 11.477 mm | 27.569 mm |
| 去噪加空槽标量校正 | 1.295 mm | 2.078 mm |
| 去噪加空槽空间校正 | 1.295 mm | 2.079 mm |

单独去噪没有显著改善液位，较差噪声下还略有增加。主要液位收益来自独立参照消除公共偏移、使用更完整的空间支持，以及避免在普通漫反射场景中拟合没有物理依据的液面与底面混合比例。不能把整个收益说成去噪算法贡献。

空间校正与标量校正的液位MAE几乎相同，但前者能更好修复自由平面倾角。这与重力约束液位主要依赖整体偏移、倾角依赖空间误差结构相符。

## 异常点与时变噪声限制

| 条件 | 旧远浅MAE | 新远浅MAE | 新P95 | 新通过率 |
| --- | ---: | ---: | ---: | ---: |
| 2%离散异常点 通常噪声 | 5.19 mm | 1.41 mm | 3.99 mm | 98.44% |
| 2%离散异常点 较差噪声 | 21.52 mm | 2.14 mm | 6.33 mm | 96.48% |
| 空间噪声相关性0.5 较差噪声 | 25.85 mm | 23.12 mm | 64.31 mm | 32.03% |
| 空间噪声相关性0 较差噪声 | 34.82 mm | 32.35 mm | 89.83 mm | 29.30% |

时变条件下数值覆盖率仍为100%，但不等于准确率合格。自适应空间迁移权重的中位数分别约0.49和0，符合噪声变化趋势；它不能识别空间变化产生的公共分量，远浅液深仍有厘米级误差。残差相关性降低只是减少错误复用，不创造可观测的绝对液位参照。

这类剩余误差不是“真实液面点太少”，也不能直接认定为硬件不可突破的理论下限。更合适的后续方法是测量期间观察一个已标定固定参照区域，独立校验漂移；只有没有可见参照时，再验证多帧估计和定期更新空槽校正。实现这些方案前需明确参照是否在实物中可见，不能用仿真真实液深充当部署输入。

## 代码与复现

服务器项目新增文件：

- `src/liquid_depth/ordinary_surface_v40.py`：安装几何准备、空槽标定、视差去噪、标量和空间残差校正、自由平面诊断。
- `scripts/experiment_ordinary_v40.py`：独立普通场景及敏感性试验。
- `scripts/analyze_ordinary_v40.py`：完整误差分布、空间支持诊断、分距离统计和配置级自助抽样。
- `tests/test_ordinary_v40.py`：数值范围、负液位、孔洞、边界、标定一致性和公共偏置测试。

最小接口：

```python
from liquid_depth.ordinary_surface_v40 import prepare, calibrate, estimate
context = prepare(installed_calibration, rim_z_m, empty_depth_m.shape, baseline_m)
reference = calibrate(empty_depth_m, context)
result = estimate(current_depth_m, context, reference, mode='paired')
```

`installed_calibration`来自实际标定，不是测试真值。安装几何在初始化时准备，空槽仅采集一帧；每个新测量帧独立输出，不消耗额外标注先验。相机移动、基线、内参或容器几何变化后需要重新建立上下文和空槽参考。

项目绝对路径为`/root/autodl-tmp/Liquid-Surface-Detector-based-on-CV`。最终测试目录为`/root/autodl-tmp/liquid-depth-artifacts/evaluation/ordinary-v40-test-20261012-final`；异常点和时变噪声目录分别将`test`换为`outliers`、`rho05`、`rho0`。各目录保存逐帧记录、协议、源代码哈希、完整分层统计和分析JSON。源代码哈希对应最终验证版本。

本试验只验证主动双目计量支路；ToF、相移结构光、实际RGB和IR匹配过程没有在这轮得到新增性能验证。既有神经网络的输入归一化与其他场景默认链路未改动，不能声称整个系统已取消所有旧模型内部的归一化上限。

## 验证与运行耗时

最终安装标识包含内参、位姿、容器几何、图像尺寸和双目基线，防止错误复用空槽参考。32项新旧相关测试通过。四组最终实验共32000条方法级逐帧记录，与校验修订前版本的数值和诊断字段完全一致，只有运行时间不同；最终协议中的算法源代码哈希全部核对一致。验证保存在`/root/autodl-tmp/liquid-depth-artifacts/evaluation/ordinary-v40-verification-20261012.json`。

服务器CPU单BLAS和OpenMP线程、单OpenCV线程，对两个原生1280乘800输入进行40次重复测量，新增计量处理P50为32.46 ms，P95为33.18 ms。安装几何准备约129至170 ms、空槽参考建立约26至27 ms，均属于初始化。测量耗时不包含相机曝光、USB或网络传输、RGB和IR匹配、深度学习模型以及界面刷新，不能把33 ms称为整套系统端到端延时，也不能用两个输入的计时代表所有安装。
