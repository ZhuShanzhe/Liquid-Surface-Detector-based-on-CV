# RGB-D工业液深智能测量系统 V1.0 用户手册（草案）

## 1. 文档状态

本文件是软件著作权登记候选文档和产品用户手册的持续维护稿。软件名称、著作权人、完成日期、
发布状态和最终截图在 V1.0 冻结前确认。当前版本仍处于研发阶段，不构成计量认证或安全承诺。

## 2. 软件用途

系统读取同步的 RGB 图像、深度图和相机内参，识别液面及容器区域，修复透明、半透明和强反光
造成的异常深度，结合标定后的容器底面与物理约束计算垂直液深。系统同时输出置信度、质量判定
和拒绝原因，供工业监控、实验测量和后续控制系统使用。

## 3. 功能组成

1. Orbbec RGB-D 相机同步采集与帧目录落盘。
2. 录制数据回放和统一输入校验。
3. 液面、容器边缘和无效深度区域检测。
4. RGB-D 深度修复、表面法向和不确定度预测。
5. 液面内部鲁棒平面拟合与弯月面边界处理。
6. 容器底面标定、重力方向和几何一致性约束。
7. 滑窗或鲁棒 Kalman 时序滤波。
8. 液深、置信度、接受状态和拒绝原因输出。
9. 场景分层精度评测、服务器健康检查和模型导出。

## 4. 运行环境

研发服务器使用 Linux、Python 3.10 及以上、CUDA PyTorch 和 ROS 2 Humble。相机在线采集依赖
Orbbec 官方 ROS 2 驱动；离线回放与算法评测不要求在服务器连接相机。第三方驱动、数据集、
模型源码和预训练权重分别存放，不属于本软件原创源码交存范围。

## 5. 安装

在服务器克隆带子模块的仓库后执行：

    git clone --recurse-submodules <repository>
    cd Liquid-Surface-Detector-based-on-CV
    bash scripts/bootstrap_server.sh
    conda activate /root/autodl-tmp/envs/liquid-depth
    pytest -q
    python scripts/audit_system.py --require-cuda

正式 V1.0 将冻结依赖版本并记录相机固件、驱动版本、CUDA、PyTorch 和操作系统信息。

## 6. 输入数据

每帧目录至少包含 RGB 图像、米制或带明确比例系数的深度图以及相机内参。RGB 与深度必须时间
同步并完成坐标对齐。输入校验脚本检查尺寸、数值范围、无效深度比例和必要元数据：

    python scripts/validate_frames.py <frame-root> --output <audit.json>

原始图像、客户数据和标注不提交到 Git，也不进入软件著作权源码材料。

## 7. 底面标定

固定相机与容器后，使用空容器帧拟合底面：

    liquid-depth --config configs/pipeline.yaml fit-bottom \
      --frame <empty-container-frame> \
      --output <bottom-plane.json>

标定只对相同相机、镜头、分辨率、安装位姿和容器几何有效。任一条件变化后必须重新标定。

## 8. 单帧推理

    liquid-depth --config configs/pipeline.yaml infer \
      --frame <rgbd-frame> \
      --bottom-plane <bottom-plane.json> \
      --output-dir <result-directory>

输出目录包含机器可读 JSON 和诊断信息。下游控制逻辑只能使用 accepted 为 true 的结果。

## 9. 批量与视频处理

批量命令对帧目录逐一推理，视频模式在单帧结果上进行鲁棒时序融合。滤波器不能掩盖持续偏差；
当液面支撑点不足、平面角度异常、预测不确定度过高或时序跳变过大时，系统应拒绝输出。

## 10. 输出字段

主要输出包括：

- liquid_depth_m：垂直液深，单位为米；
- uncertainty_m 或 confidence：预测不确定度或置信度；
- accepted：本帧是否通过质量门；
- rejection_reasons：拒绝原因列表；
- mask、depth、plane 和 temporal diagnostics：可追溯诊断；
- software_version、model_version 和 calibration_id：版本与标定标识。

V1.0 冻结时将把完整 JSON Schema 作为附录。

## 11. 精度与验收

精度配置位于 configs/accuracy_profile_industrial_v1.yaml。液深按 20-200 mm 压力测试、
0.2-1 m、1-5 m 和 5-10 m 分段。单样本允许误差采用绝对毫米下限与相对误差的较大值，
避免小液深时出现不可实现的亚毫米百分比要求。

1-10 m 的研发目标为平均误差尽量达到约 1%；同时报告 P95、系统偏差、时序抖动、接受覆盖率
和误接受率。5-10 m 是否能达到 1% 取决于经过实测认证的相机与安装配置，未通过验证时必须
降级、拒绝或更换长基线双目、ToF、激光或其他硬件。

## 12. 困难场景

透明液体、半透明液体、强反光、饱和高光、容器边缘、弱纹理和多层折射必须单独统计。系统用
多任务网络预测液面、深度或几何偏移、法向和不确定度，再通过内区平面、弯月面、重力、底面
平行和历史液深约束完成估计。无法可靠感知的场景不强行给出数值。

## 13. 常见拒绝原因

- 输入文件缺失、时间不同步或内参不匹配；
- 有效深度或液面内点不足；
- 液面与底面夹角超过物理阈值；
- 透明、眩光或饱和区域不确定度过高；
- 标定不适用于当前相机、容器或分辨率；
- 液深超出 0.02-10 m 已定义评测域；
- 视频结果发生不合理跳变；
- 相机工作距离超出该模式经过认证的范围。

## 15. 当前限制

目前工业距离范围的可追溯液深数据尚未完成采集，DTLD 只覆盖约 15-96 mm，不能证明 0.2-10 m
性能。当前直接液高回归模型在 DTLD 场景迁移上误差较大，因此后续采用“深度学习感知与
不确定度 + 显式容器几何 + 物理与时序融合”的产品路线，而不是依赖黑盒回归给出工业读数。
