# 场景链路边界与透明诊断协议 V25（2026-10-11）

Update 2026-10-14: This V25 route history is retained for special-scene
research. The current supported three-scene simulation interface is
`liquid_depth.FormalSceneMeter` in `src/liquid_depth/supported_scene_meter.py`;

## V32 零位与薄弱液深区间优化（2026-10-12）

[V32新独立配对测试](transparent_focus_v32.md)保持空容器＋4组已知液深先验、实际H为0–9 m、相机到底面B≤10 m；不强制归零、不裁剪容量、不按置信度或覆盖率筛帧。仅改为逐参考/左右通道校准、单调三次反解和软鲁棒融合，图像配准器与V31相同。

8016组含加密薄弱区间的测量中，零位MAE为5.79→4.92 mm、通过52.95%→62.67%；0<H<1 m为11.17→5.74 mm、50.36%→75.14%；2≤H<3 m为44.49→7.67 mm、57.14%→100%。其中3504组均匀子集MAE为23.35→10.26 mm、通过87.99%→97.20%，不能与不同采样分布的旧总平均直接相比。

透明零位通过80.99%，两档半透明仅52.60%–54.43%，2–100 mm半透明浅液位仍偏弱。零位MAE改善的聚类置信区间跨零，不能称彻底解决；最大尾部误差270.82→284.67 mm，少量高位外推仍需警告。所有帧数值输出率100%不等于可信覆盖率。底纹消失、强散射和小容器不纳入本轮优化；生产默认、安全门控及V31历史证据保持不变。

## V31 实际液深范围约定（2026-10-12）

本轮实际液深上限按用户要求改为9 m；相机到底面距离仍不超过10 m。H为底面相对液深，不能与相机深度Z或相机到底面距离B混用。[V31全量程研究](transparent_range_v31.md)使用0–9 m等间距液深、固定有限底纹、空容器加4组已知液深先验及放宽门控，报告所有帧与每1 m区间结果；0 m不定义AbsRel。低于96原生像素的小容器不再作为优化对象。

光程增大后半透明底纹可能不可观测，不能保证同一种材料在全液深范围都属于“底部可见”链路。底纹消失的旧材料单列边界审计，不参加透明优化选型。新配准与单调响应校准为独立研究代码，原有工业默认与安全门控保持不变，不能将数值输出率作为可信覆盖率。

## V30 有限底纹与小像素验证（2026-10-11）

[V30独立全帧测试](transparent_finite_v30.md)将底纹限制在实际容器范围内，保持空容器＋4组有液先验。1728组新测试中，冻结候选全部产生数值，容差通过65.22%，但MAE为67.15 mm，差于直接配准物理模型对照的19.68 mm；低于32像素的弱响应反解出现严重尾部错误，因此不推广为默认工业算法。

至少96像素宽的576组为1.38 mm MAE、96.01%通过；低于32像素的384组为290.17 mm、8.33%通过。9.6 m处75像素宽的容器为2.03 mm、93.75%，19像素宽则为544.10 mm、2.60%。像素分层是受控测试证据，不是新的生产自动切换阈值。`FiniteBottomRelativeMeter`仅复现研究候选，默认生产路线与安全门控不变；有限数值和理想对应点归因结果都不能作为可信覆盖率。

## V29 空容器＋4帧与相对位移研究（2026-10-11）

[V29 独立全帧测试与常驻研究接口](transparent_relative_v29.md)比较原5帧有液标定与容量内空容器＋4帧。开发集冻结选择为均衡布置0/15/40/65/90% C的多参考相对位移＋有界残差；算法接口允许任意合法递增已知液深，并未写死比例。新的864组双目透明/轻度半透明测试全部满足max(5 mm,2%H)，MAE从6.674降为0.691 mm；B≥6 m的576组从9.592降为0.764 mm。

收益来自跨液位底纹观测，不能只归结为增加空图。全帧数值输出及容差通过不等于生产可信覆盖率；严格逐帧1%仅621/864，H≥10 cm为395/432。相机/容器/底纹需稳定、底部可见、共用整流内参及顶视水平几何已知。宽视野无限底纹、H/B散射代理不证明有限尺寸小容器、相机运动、强散射或硬件性能。默认工业路线和安全门控不变；`FixedCameraRelativeMeter`为独立未认证研究接口，细节与延时见报告。

## V28 实际容器最大液深限制研究（2026-10-11）

[V28 容量内5帧先验与误差归因](transparent_capacity_v28.md)将所有先验约束在实际最大液深C内，并明确区分相机到底面距离B与实际液深H。独立测试720组全部保留、无置信度/覆盖率筛选。开发集选定布置的全帧MAE为4.085 mm、通过585/720，均匀基线为4.142 mm、通过587/720；配对改善区间跨零，因此不作为已验证改进推广，不根据测试结果改选布置。

远距离浅容器仍是主要不足，尤其双目；联合理想化先验与测量对应点的诊断指向匹配偏置及窄跨度标定耦合。该反事实使用真值，仅作归因。平底无限视野、已知几何及H/B散射代理的限制详见报告，不能作为有限尺寸真实容器或工业精度认证。生产默认与安全门控保持不变，研究入口 `scripts/run_capacity_v28.py`。

## V27 远距离浅液位研究（2026-10-11）

[V27 5帧先验布置与残余偏置报告](transparent_shallow_v27.md)比较四种相同5帧预算的布置，并将开发集选中的布置和偏置策略冻结后进行新的独立全帧测试。仍仅针对顶视均匀透明/轻度半透明液体，不启用输出置信度或覆盖率筛选，不更改默认工业链路。

## V26 透明链路进展（2026-10-11）

最新独立研究实现及全帧结果见[透明半透明 V26 校正与相位优化](transparent_refinement_v26.md)。新增有界经验残差、双目周期性亚像素偏置校正和结构光块内相位聚合。V25 原320组与新增320组均不做输出置信度/覆盖率筛选，最终分别311/320组满足液深容差；不表示100%可信覆盖率。研究入口为 `scripts/run_transparent_v26.py`，原V25源码和历史证据保留。

V26 不改变以下主链路边界，不将强散射、多界面或默认工业运行端纳入此次优化。结构光一次测量需要30次曝光；数值输出仍为 `qualified=false`，尚未完成实际相机集成与端到端认证。

## 本轮变更

透明方向只优化透明与仍能观察到底部纹理的轻度半透明均匀液体。不以强散射压力样本参与选型、阈值选择或测试平均数。强散射历史样本留档，不删除，也不能把底部回波图像直接交给普通表面链路并宣称完成验证。

不再以达到固定覆盖率作为本轮研究筛选条件。评估保留每个测量帧，分别列出数值输出、无法求解、精度通过与警告。有限数值不等于产品认可结果；工业运行端原有安全门控不取消。

## 主链路与边界

| 主链路 | 纳入的场景与观测依据 | 不纳入/另行处理 | 当前代码与状态 |
|---|---|---|---|
| 普通表面测量 | 可确认回波位于液面；普通不透明液体，以及具有可靠表面回波的强散射液体 | 底部错误回波、明显体散射穿透偏差、未确认回波来源 | `pipeline.py` 的分割、深度修复、面拟合、底面相对高度；`system_runtime.py` 的接触线/容器几何路线。两者不是同一个算法 |
| 均匀透明/轻度半透明折射校正 | 顶视；单一均匀液体；底面/相机几何已知；底部纹理或投影可匹配；几帧已知液深先验 | 光路穿玻璃侧壁、多层液体、强散射、底纹完全消失、显著非平面液面；V29相对路线还不支持相机/底纹变化 | V22–V29 独立研究模块；V29 空容器＋4帧相对位移显著改善本轮受控仿真；尚未接入默认工业运行端 |
| 多层透明候选选择 | 同一光线经过额外容器壁/多界面，需先区分液面层与其他层 | 不允许用单一均匀折射模型冒充多界面解算 | `surface_candidates.py`、V19/V20 折射证据/共识与历史透明 specialist；研究路线，不是本轮优化对象 |
| 严重信息缺失/未知 | 无可靠液面回波也无可匹配底纹；场景判定矛盾 | 不强行划入普通或透明以提高覆盖率 | 原有记忆/失效路线或明确无法评估；不在本轮继续优化 95%–100% 失效 |

## 附加条件不是液体主类别

| 条件 | 对应已有模块 | 边界说明 |
|---|---|---|
| 低照度 | `illumination.py`、low_light specialist 槽位 | 改善成像，不据此判定折射率/是否强散射 |
| 眩光/饱和 | glare specialist、质量评估 | 饱和不是强散射；按可用区域处理 |
| 漂浮物/边缘 | 分割、`surface_support.py`、鲁棒面估计 | 遮挡部分剔除/另行建模，不能作为液面点 |
| 不平整/波动 | 表面支持与相应研究评估 | 最低/最高/平均液深另评；V25 平液面仿真不声称覆盖 |
| 大面积深度失效 | `anchor_memory.py`、`surface_memory.py`、时序及相关研究模块 | 历史信息需对齐；不改本轮透明的静态实验为时序结果 |

## 可执行边界字段

`scene_context.json` 新增可选字段 `measurement_route`，支持 `surface`、`homogeneous_refraction`、`multilayer`。旧文件未填写时保持原行为，并输出 `legacy_unspecified`，不声称旧触发器已能辨别液体物理类别。

普通/强散射表面路线示例：

```json
{
  "measurement_route": "surface",
  "liquid_optics": "strong_scattering",
  "surface_return_verified": true
}
```

`surface_return_verified` 是安装验证/操作配方提供的证据，不是系统根据灰度自动推出的事实。未确认时有明确原因，不直接输出可信结果。选择该路线后，透明提示不再单独激活透明 specialist；低照、眩光和失效触发仍保留。切换主路线清空原场景的滞后保持。

透明研究路线示例：

```json
{
  "measurement_route": "homogeneous_refraction",
  "liquid_optics": "translucent_mild",
  "bottom_pattern_visible": true,
  "glass_wall_in_optical_path": false,
  "multi_layer_expected": false
}
```

工业运行端对该配置明确返回 `research_route_not_integrated`，不会用一个同名网络权重替代左右目/投影数据的折射求解。实际 V25 实验入口为 `scripts/experiment_transparent_v25.py` 和 `scripts/run_transparent_v25.py`。

## 无强制覆盖率筛选的诊断

- 每帧记录真实液深（仅评分使用）、原始估计、误差、匹配区数、外推/边界警告、推理时间。
- 液深始终相对容器底面。通过容差仍用 `max(5 mm, 2% × 真实液深)`；本轮不修改精度标尺。
- 数值输出率 = 有有限数值的测量帧/全部测量帧；不是安全覆盖率。
- 通过率分为有限数值条件下通过率和全帧通过率；无法求解帧计入全帧分母。
- 不确定度筛选不参与本轮诊断；无匹配、非法标定、数值失败仍保留明确失败，不编造液深。
- 模型选择仅使用开发集透明/轻度半透明样本的容差归一化误差；缺测给固定惩罚。没有最低覆盖率约束，不根据未知测试液深选择路线。
- 先固定方法和源码，再生成独立纹理种子、不同折射率与液位测试。相机到底部距离分层与实际液深分层分开。

## 回退与保留

V24b 原先是保留所有 V23 已接受预测、仅增加补充输出，未修改生产默认算法。本轮核查既有 240 个透明/轻度半透明测量帧，先区分同帧是否退化与新增难帧拉高平均误差，不能直接比较不同筛选集合的 MAE。

不删除 V24b 历史证据；其混入强散射的参数选择不再用于当前透明方向选型。V25 是显式独立诊断模块，不替换生产模型。若某候选在本类场景表现更差，记录失败并不采用；不要求跨场景统一一个修正方法。

## 仿真证据边界

使用有限基线、Snell 几何、灰度左右图或 30 张结构光编码图，含强度噪声与轻度散射代理。前向与逆向共享平底/平液面的物理假设；没有真实相机硬件噪声标定、玻璃侧壁、动态波浪或真实浊度量纲。本实验验证受控条件下算法问题，不是工业硬件精度认证。结构光 30 次曝光的采集时间不能被单帧求解耗时替代。
