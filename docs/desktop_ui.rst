离线仿真桌面操作面板
====================

用途与边界
----------
面板是实地部署的交互模板；当前数据来源是软件自带仿真，而非 USB 相机或 PLC。
正式 V14 液深/最高高度测量核心未因界面而修改。仿真真值只用于显示与事后误差计算。
所有页面、样式、脚本与三维投影均来自本地资源，没有 CDN、网络字体或第三方在线脚本。

操作流程
--------
1. 在“安装与标定”选择圆柱、椭圆柱或矩形容器，输入完整内尺寸与内高度。
2. 输入相机到底面距离与顶部偏心 X/Y。相机竖直俯视；偏心各不超过对应半径/半宽的 25%。
3. 默认使用自动构图与固定 10 mm 高斯先验误差；诊断时可切换理想标定。
4. 在“运行工况”确认材质，设置液深、照明、眩光、起伏、漂浮物与深度缺失。
5. 点击“生成并测量”。安装、材质、光学参数或标定模式变化时自动重建空槽与先验。
   运行工况变化复用该安装的标定；“重建先验并测量”显式重新初始化。
6. 左侧显示可旋转、平移、缩放的真实三维场景、估计液面轮廓与可选测量点云，
   下方显示本帧 RGB 和 ToF 深度伪彩色图。右侧对照真值与估计值。

参数说明
--------
* 圆柱尺寸为内直径，X/Y 自动联动；椭圆为完整轴长；矩形为内宽、内长。
* 透明/半透明可设置折射率、表面回波权重；半透明另可设置消光和散射。
  这些值属于仿真器物性，不直接交给测量逆解；测量依然使用 5 帧已知液深先验。
* 光照、眩光和缺失滑条为仿真控制量，不等价于真实相机照度或本帧实测缺失率。
* 正式性能报告液深范围为 0.10–9.00 m。空槽或发布采样范围以外的尺寸、安装等
  可供诊断探索，但面板明确提示其不能沿用报告通过率。
* 透明/半透明仅支持均匀、无遮挡、平整液体；与起伏或漂浮物的组合不开放。

结果与时延
----------
没有漂浮物或起伏时，最高高度显示不适用。液深容差为 max(20 mm, 2% 实际液深)；
起伏液面和最高高度为 max(50 mm, 5% 对应实际高度)。这些仅为本帧仿真对照，
不是现场精度认证。分类评分不是测量置信度，分类标签不作为通过标准。

测量计算、仿真采集、初始化分别计时。改变参数后仍显示上一帧结果时会明确标记，
不将旧值当作新测量；不合格输入直接显示跳过，分类和测量均不执行。
前端只提供即时输入检查，服务器校验和独立仿真输入资格检查仍为最终判据。

验证
----
``node tests/desktop_ui_contract.mjs`` 检查前端控件、无外部资源、形状投影、
参数边界、状态与时延分离；测试载荷明确为合成界面单测，不是性能数据。
发行前仍需对桌面内嵌 WebEngine 做真实显示与交互验收。
