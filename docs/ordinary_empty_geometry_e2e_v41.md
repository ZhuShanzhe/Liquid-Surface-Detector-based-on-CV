# 空槽建模普通液面链路完整评估

日期：2026年10月12日。

在顶部固定相机、规则容器、可靠漫反射表面返回及稳定安装噪声的受控仿真中，空槽建模后的普通链路具备毫米级平均液深误差。推荐的实测底面垂距方案，在0至9米均匀液深测试中，正常噪声 MAE 为4.94毫米，较差噪声为5.76毫米；较差条件下仍有3.24%的帧因初始化失败而没有数值输出。底面法向偏差、几何参照误差及空槽空间残差随时间漂移仍是主要限制，不能由这些结果宣称工业现场全量程保证1%。

本轮仅新增评估、分析和计时脚本，未调参、训练、改变测量值或放宽算法中的校核条件。此前128组底层调用验证保留；以下是新的完整运行接口评估，不与旧测试合并。

## 测试范围和完整链路

本次实际执行“原生帧文件读取 → 单帧空槽建模与校核 → 保存 YAML 和标定资产 → 通过 `make_product_system` 载入 → 调用 `measure` 读取液体帧 → 返回候选液深”。输入深度以毫米保存，运行时按方案转换为米。比较两种人工参照：底面尺度线和光心到底面实测垂距。理想真值几何仅用于单独的参照方法，不传给这两种拟合方案。

主测试包含360个独立容器安装配置：0至9米每个一米液深区间24组，远距离浅液位96组，空槽24组，5至100毫米近零液位24组。另有18组固定容器液位扫描，保持同一容器、内高、相机和空槽标定，改变多个实际液深。每种噪声条件、每个测试液深采集4帧独立噪声观测；这是重复测量，不是4帧联合估计。

两种噪声条件下主测试共2880个观测，固定容器扫描共1712个观测，合计4592个观测。三个方法合计13776条结果；不能把共享观测的方法记录或同一安装下的重复帧当成独立场景。

| 条件 | 本轮设定 |
| --- | --- |

| 容器和安装 | 圆形、椭圆和矩形，平整水平底面、竖直侧壁、顶部固定相机；相机至底面中心不超过10米 |

## 指标和分母

液深是相对容器内部底面的实际高度，误差不以相机测距作分母。MAE 为有数值输出帧的绝对误差均值，AbsRel 为正液深输出帧的 `|预测液深−真实液深|/真实液深` 均值；空槽相对误差不定义。P95 表示95%的有输出帧绝对误差不超过该值。

诊断通过条件为 `|液深误差|≤max(5 mm, 2%×真实液深)`，通过率和数值输出率都以全部对应测试帧为分母，初始化失败也计入。该条件用于延续项目对比，不是厂商或工业设备的认证标准。相对误差分布另列，不能只用通过率衡量精度。

新链路尚未现场验收，始终返回 `accepted=false`，有效工业输出率为0；以下数值输出率仅指候选液深可计算。高数值输出率不代表误差小，也不代表已允许工业控制。

各组正常噪声数值输出率均为100%。均匀液深 AbsRel 正常为0.144%，较差为0.178%；但5至100毫米组分别为4.91%和6.83%。这不是算法在近零处突然出现几厘米平均误差，而是1至2毫米误差除以极小真实液深后的结果。该组相对误差不超过1%的帧比例只有31.25%和17.71%，因此不能声称极浅液位也已经达到逐帧1%。

按安装配置而非重复帧进行2000次聚类重采样，均匀液深 MAE 的95%区间正常为4.32至5.60毫米，较差为4.99至6.68毫米；较差条件诊断通过率区间约93.98%至99.07%。这些区间反映本轮抽样不确定性，不包含仿真到真实相机的系统偏差，也不代表未输出帧的误差。

## 两种人工参照的差别

| 均匀液深测试 | 尺度线 MAE mm | 垂距 MAE mm | 尺度线 P95 mm | 垂距 P95 mm |
| --- | ---: | ---: | ---: | ---: |
| 正常噪声 | 14.58 | 4.94 | 40.23 | 15.24 |
| 较差噪声 | 19.74 | 5.76 | 65.24 | 16.88 |

较差条件的输出集合略有不同。在两方案共同输出的836帧上，尺度线 MAE 为19.41毫米，垂距为5.76毫米，垂距约80.74%的帧误差更小。此配对比较排除了不同初始化失败集合对均值的部分影响。垂距不能随意用相机外壳的斜距代替，真实实测精度也必须满足设定。

理想几何参照的均匀液深 MAE 只有0.35和0.52毫米；加入实际需要估计的容器几何后误差增大，说明下一步不能只看液面点云去噪，还需要提高初始化准确性。尺度线的实测和点击误差会转换为底面尺度偏差，深液位更容易体现该偏差。

固定容器扫描中，在忽略倾角及 ROI 变化的一阶近似下，底面垂距误差 δ 对液深误差的影响约为 `δ×[2h/B−(h/B)²]`，B 是真实底面垂距，h 是真实液深。拟合误差与这一仅用于事后解释的几何误差代理呈较强相关；垂距方案正常约0.987、较差约0.922。此诊断使用真值，不传入运行算法，也不能代替具体误差归因。

较差噪声下，最大尾部实例真实液深5.729米、误差约55.7至56.9毫米，四次重复都保持相似偏差。其底面垂距实测误差约10.2毫米，而从空槽深度估计的法向与真值偏差达8.70度；独立校核线误差24.2毫米、相对1.80%，仍通过现有2%的粗校核。另一个8.122米实例的法向偏差约7.41度，液深误差约28.8毫米。足够多的真实底面返回点不意味着拟合方向一定准确，空间相关噪声可形成错误倾斜趋势，且一条尺寸校核线不能充分约束三维方向。

## 初始化失败及长期噪声漂移

推荐垂距方案在较差条件下有11个安装配置初始化失败：8个独立尺寸校核失败，3个普通链路的空槽共同可观测点不足，对应44个主测试帧无输出。均匀分组占28帧，远距离浅液位占16帧。正常噪声和18组固定容器扫描没有初始化失败。共同可观测点不足不表示全图没有底面深度，也可能是估计姿态使底面与开口的保守取样交集过小。

为独立检查对历史空槽残差稳定性的依赖，另取72组安装配置，在同一批场景及随机种子上比较空间噪声保留参数1.0与0.5。正常噪声不注入该空间漂移；下表只列较差噪声、垂距方案。参数0.5是噪声场相关性的敏感性假设，不是50%像素失效，也不是某款相机实测概率。

| 分组 | 稳定 MAE mm | 漂移 MAE mm | 稳定通过率 | 漂移通过率 |
| --- | ---: | ---: | ---: | ---: |
| 均匀液深 | 6.28 | 9.50 | 93.06% | 88.19% |
| 远距离浅液位 | 2.41 | 22.57 | 92.71% | 26.04% |
| 5至100毫米近零液位 | 1.82 | 20.05 | 91.67% | 12.50% |
| 空槽 | 1.88 | 15.42 | 95.83% | 16.67% |

漂移测试中远距离浅液位数值输出率仍为95.83%，但通过率只有26.04%。这表明放宽测量门控能暴露退化，却不能凭高输出率认定可靠：旧空槽噪声图不再代表当前误差时，会把错误校正带入当前液深。该问题属于标定及噪声模型的时变不足，不是本次仿真中液面缺乏返回点的证据，也不能据此推断具体硬件的长期性能。

## 延时及下一步优先级

在24组成功初始化配置上串行计时192次，包含近远液位、三类容器和两组噪声，使用暖缓存。读取帧与 CPU 计算 P50 约43.10毫秒、P95 约48.22毫秒；计入 JSON 保存和叠加图编码落盘后 P50 约50.79毫秒、P95 约55.91毫秒，最大约62.70毫秒。本次没有样本超过500毫秒，但不包含相机曝光采集、数据传输、网络和 GUI 排队；不是完整硬件端到端0.5秒保证。

现阶段普通非极浅液位、噪声稳定且初始化成功时，性能可以作为后续现场验证的基础。优先处理的是独立重力或更多方向参照对底面法向的校核、较差噪声下的几何可用性，以及旧空槽空间残差的有效期和漂移检测。空槽和毫米级浅液位应单独使用绝对误差评价，不能依赖均匀0至9米平均相对误差掩盖其不足。

没有根据本次结果改变默认算法，也没有通过缩小量程、归零、裁剪或筛掉失败配置提高指标。透明、半透明、眩光、漂浮物和大面积失效不属于本报告已验证的普通场景。
