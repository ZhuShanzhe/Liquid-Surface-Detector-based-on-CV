正式 ToF V14 输入、模块和验收边界
================================

版本：2026-10-21。正式软件入口不等于现场计量认证。
原确定版对称几何基线及历史报告保留；不修改其冻结源码或原始结果。

统一链路
--------

::

  RGB + ToF原始深度 + 有效性标志 + 空槽标定 + 已确认材料
                |
       前置输入检查（不合格不测量）
                |
       已确认材料选择物理后端，互斥
          /                           \
  普通/漫反射                       均匀透明/半透明
       |                               |
  四标签辅助分类                    原始AMCW相关量
       |                            空槽+4帧已知液深先验
  原对称候选 + 当前三维内部筛选          |
  空槽-湿帧身份 + 空间一致性         原相位折射校正
       |                               |
  液深输出（不使用视觉语义改写）       液深输出
       |
  波面几何最高点 / 可选漂浮物视觉最高点
  小漂浮物存在性探针兜底
       |
  两高度、执行模块、诊断与耗时

低照、眩光和部分丢失是观测修饰，不叠加重复数值校正；分类输出不等于真实回波身份。
视觉漂浮物模块和小目标探针只允许修改最高高度，不修改液深。
V14几何补救不再要求一个湿帧像素在空槽时必须看见底面，而使用当前XYZ的容器内部
约束和早于空槽的回波证据；不强制归零、不裁剪估计值、不向测量器传入当前真值。

公开入口
--------

推荐统一工厂：``liquid_depth.formal_tof_runtime.create_formal_meter``。
普通材料采用经过数值对照的V13辅助分类及V14几何修复；确认的透明/半透明材料
保留原相位流程，不自动退回普通几何。仅深度接口
``ToFSceneMeter.from_empty_geometry`` 也默认采用V14几何补救。

服务器源代码启动展示（尚不打包桌面程序）：

::

  PYTHONPATH=src:scripts OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 \
  python -m liquid_depth.scene_console_web \
    --work /absolute/path/to/captures \
    --checkpoint assets/models/scene_router/scene_head.pt \
    --port 8765 --blender /absolute/path/to/blender

服务只监听127.0.0.1，通过已有SSH转发访问；保留同源检查和请求令牌。
正式GPU执行档案是Linux、CUDA、g++、FP32神经推理、FP64树阈值；首次编译/模型加载
和预热计入初始化，不计入暖态测量耗时。模型资产均需通过哈希与sklearn版本验证。
此处是服务器源代码部署流程，不是独立wheel/EXE打包承诺。

初始化和输入有效性
------------------

相机顶部固定安装；改变容器高度、相机到底面距离、视场或材料后重新标定。
仿真自动提供准确的独立尺寸、重力/位姿和空槽先验，不用当前测试液深标定。
自动构图保持完整槽口及12%边距，必要时调整相机并回填实际距离，≤10m。
现场仍需真实内参、RGB/深度配准、空槽/独立尺寸或标尺以及材料确认。

仿真在分类和测量前使用生产端可见性检查：有效液面返回≥30点、跨度≥3px、
实际可见液面深度缺失≤50%；有漂浮物时有效返回≥3点且跨度≥2px。
不合格帧不运行分类和测量，不计入合格输入覆盖率的分母，但必须单列排除数量和原因。
该检查使用模拟器可见性，不是现场可用的真值判定，不能伪装成真实部署能力。

功能性验收
----------

* 液深：相对容器底面，普通容差max(20mm,2%实际液深)。
* 波面液深：max(50mm,5%实际液深)。
* 最高高度：max(50mm,5%真实最高高度)。
* 功能通过：液深通过，有波面或漂浮物时最高高度也必须通过。
* 同时报告两个高度各自通过率、双高度同时通过率、数值覆盖率、MAE/P95/最大误差、
  绝对和相对误差分布，以及延时P50/P95/最大值、超500ms帧数。
* 标签组合完全正确只作诊断。标签不一致但测量合格同样计为功能合格；
  标签正确但数值超差仍是失败，无输出也计失败，不得根据误差删除合格帧。

当前强复合扩充验证包含低照、眩光、波面、漂浮物四现象中至少两种同时出现的
11种组合，每种至少100个合格帧，另叠加允许范围的深度丢失。
不声称覆盖透明/半透明与漂浮物或波面的跨机制复合，不声称支持>50%深度失效。
冻结源码、逐帧结果、资格与跳过原因、性能分布、部署和回退记录均保存在服务器。
历史测试的406帧数值一致性与本轮新增强复合测试应分开解释。
