# 工业液深测量产品部署与标定说明

## 1. 两种部署模式

系统从同步 RGB-D 帧读取彩色图、原始深度和相机内参，经液面接触曲线网络、几何或标尺换算、质量门控和时序滤波，输出米制液深、置信度、不确定度与拒绝原因。

| 模式 | 相机状态 | 必需现场输入 | 移动后的处理 |
| --- | --- | --- | --- |
| 固定/偶尔移动 fixed_rail | 一次测量会话内固定 | 静态同步帧、容器区域、同一测量线上的已知深度点 | 相机或容器明显移动后重新点选标定 |
| 持续移动 cad + marker_tracking | 测量中持续移动 | 容器 CAD 或等价三维点云、内参、固定定位标记、CAD—标记外参 | 每帧估计相机—容器位姿 |

### 强制规则

1. fixed_rail 只在相机、容器和测量参考线相对位置不变时有效。
2. 固定模式保存标定图像作为参考帧并检测容器区域位移。超过阈值时返回 camera_moved_recalibration_required，不输出有效液深。
3. 如果相机在测量过程中持续移动，必须提供 CAD（或经过尺度标定、坐标系定义完整的容器三维点云）并安装与容器刚性固定的 ArUco 或等价定位标记。
4. 没有 CAD/三维模型和逐帧位姿时，持续移动场景不属于可保证的工作模式；软件不得沿用旧二维标定给出看似有效的结果。

## 2. 为什么持续运动需要 CAD

操作人员点选的二维像素与实际液深之间的映射只对一个相机视角成立。相机平移、旋转或焦距变化后，同一液深对应的像素位置会变化。只使用旧二维标尺无法区分液面变化和相机运动。

CAD 提供容器坐标系、米制尺度、底部原点、液深方向和内壁表面。系统据此在任意已知相机位姿下把图像接触点恢复为三维高度，并检查遮挡、投影范围和重投影误差。

ArUco 不是相机或容器自带的标记。需要生成、按 100% 比例打印并刚性粘贴在容器或不发生相对运动的支架上。也可替换为 AprilTag、定位板、机器人手眼位姿或外部追踪系统，但必须提供等价的逐帧刚体位姿。

## 3. CAD 如何获得

推荐顺序：

1. 向制造商索取 STEP、IGES、STL 或 OBJ，优先索取内腔模型和尺寸公差；
2. 根据工程图在 CAD 软件中重建内壁；
3. 结构光或激光扫描后配准、定尺度并导出点云；
4. 对规则圆柱或方槽，根据实测内径、底面和高度生成参数化模型。

必须确认长度单位到米的换算、坐标系原点、正液深方向 level_axis、零液深位置 level_origin_m、模型代表内壁而不是外壁，以及 CAD 与实体关键尺寸的误差。

## 4. 固定或偶尔移动模式

### 4.1 启动

在服务器项目目录执行以下命令，然后保持终端运行：

    conda activate /root/autodl-tmp/envs/liquid-depth
    pip install -e .
    liquid-depth-panel --capture-dir /path/to/captured_frames --output-dir /path/to/measurements

面板默认只监听服务器 127.0.0.1:8765。从个人电脑访问时建立端口转发：

    ssh -L 8765:127.0.0.1:8765 -p 26663 root@connect.bjb2.seetacloud.com

浏览器打开 http://127.0.0.1:8765。

#### 4.1.1 最终操作人员流程

默认进入“日常测量”页。操作人员不需要接触服务器路径、模型文件、类别索引或标定参数：

1. 确认顶部“图像源在线”和“算法运行正常”；
2. 点击“开始自动测量”，或在调试时点击“单次测量”；
3. 只将“测量有效”状态下的大号毫米值用于记录或控制；
4. 出现“结果已拒绝”时按中文告警提示处理，系统不会用候选值冒充有效结果；
5. 停机或换班时点击“停止”，最后一次有效值会保留用于核对。

“标定向导”由现场调试人员在首次安装、相机/容器明显移动或量程变化后使用；“维护设置”仅供工程人员选择固定/移动机位模式和修改高级参数。建议实际部署时由上位机、浏览器权限或操作系统账户限制这两个页面。

日常页显示最近 30 次真实测量趋势；绿色表示有效结果，红色表示被质量门控拒绝。首次启动需要加载模型，后续测量复用同一运行实例。

### 4.2 点选标定

1. 固定相机、容器和照明，加载一帧完整同步 RGB-D 数据。
2. 框选容器和液面可能出现的区域，保留容器侧壁与参考测量线。
3. 沿同一条清晰可见的竖向测量线点击已知深度点并输入毫米值。
4. 点的位置和百分比不在代码中写死；计算完全使用操作人员实际选择的位置。
5. 数学最少 3 点，现场推荐 5 点。尽量覆盖工作量程的低、中、高位置。
6. 生成配置。系统检查竖向单调性、横向离散和深度跨度，并用留一交叉验证选择仿射或透视映射。
7. 查看留一验证 MAE。误差过大时检查真实值、点是否在同一测量线以及参考尺度。
8. 用未参与拟合的独立液深做验收，不能用拟合残差代替独立精度测试。

为什么建议 5 点：

- 3 点是最低可解数量，只能可靠使用简单映射；
- 4 点能对透视映射做留一验证，但验证样本较少；
- 5 点操作量仍低，同时有冗余来发现误点和比较模型；
- 超过 5 点同样支持，适合宽量程或透视明显的场景。

点不要求等间距，也不限制为固定百分比。“同一可见测量线”比固定深度百分比更重要。

### 4.3 相机移动

相机可以在不同任务之间移动，但移动完成后必须重新静态点选标定。以下变化均按移动处理：

- 相机位置、俯仰或滚转明显变化；
- 变焦、重新对焦导致几何变化；
- 容器或参考线相对相机移动；
- 分辨率、裁剪或 RGB/深度对齐方式变化。

轻微机械振动可由参考帧门控和时序滤波处理；超过阈值会拒绝测量，不自动猜测补偿。

## 5. 持续移动模式

持续移动模式使用 liquid-depth-system setup 创建 CAD 配置：

1. 导入相机出厂内参或用棋盘格重标定；
2. 准备内壁 CAD/点云并定义液深轴和零点；
3. 生成打印 ArUco，精确测量外框尺寸；
4. 刚性固定标记，得到 CAD 原点相对标记的位置与姿态；
5. 拍摄初始化同步帧，生成配置并检查 CAD 投影叠加图；
6. 用至少 3 个已知液深做最终输出校核；
7. 实时运行时逐帧检测标记，位姿不可见或重投影误差超限时拒绝输出。

示例：

    liquid-depth-system make-marker --id 0 --physical-size-mm 60 --output artifacts/marker_0.png

    liquid-depth-system setup \
      --frame data/setup_frame \
      --container-model models/container_inner.ply \
      --checkpoint /path/to/best.pth \
      --object-index 0 \
      --mode marker_tracking \
      --marker-id 0 --marker-size-mm 60 \
      --container-origin-in-marker-mm 0,0,0 \
      --container-rpy-in-marker-deg 0,0,0 \
      --level-axis 0,0,1 \
      --level-origin-m 0,0,0 \
      --output artifacts/moving_camera_profile.yaml

示例中的 CAD—标记平移和姿态不能照抄，必须由实测、CAD 装配约束或手眼标定得到。

## 6. 全链路与模块边界

    相机采集
      -> 同步 RGB/深度/内参
      -> 位姿或固定标定有效性检查
      -> 液面接触曲线模型
      -> 固定标尺映射 或 CAD 稀疏三维几何
      -> 置信度、几何和量程门控
      -> 鲁棒 Kalman 时序滤波
      -> 米制液深、不确定度、拒绝原因和叠加图

界面层只负责参数录入、点选、状态展示和调用接口。模型、推理、几何、标定和时序逻辑位于独立 Python 模块中。后续更换多任务网络时保持系统配置和 measure() 结果字段兼容，无需重写操作面板。

每次测量输出：

- depth_result.json：最终液深、候选值、置信度、不确定度和拒绝原因；
- contact_curve.json：曲线点与点置信度；
- measurement_overlay.png：区域、预测曲线、测量线和接受状态。

## 7. 主要拒绝原因

| 原因 | 含义 | 处理 |
| --- | --- | --- |
| camera_moved_recalibration_required | 固定模式机位已偏移 | 重新点选，或改用 CAD 持续运动模式 |
| camera_motion_unobservable | 参考区域纹理不足，无法可靠判断位移 | 增加固定纹理/标记，或改用 CAD |
| low_rail_intersection_confidence | 曲线在测量线附近置信度低 | 改善视角/照明并补充困难样本 |
| depth_outside_calibrated_range | 结果超出点选覆盖量程 | 扩展标定量程 |
| 标记或位姿失败 | 持续运动时定位失败 | 保持标记可见并检查尺寸与外参 |

## 8. 精度目标与验收

项目目标是数米量程尽量达到约 1% 相对误差，但当前研究模型不能在没有独立工业现场数据时宣称已达标。建议：

- 0.1–1 m 同时报告毫米绝对误差与相对误差；
- 1–10 m 以相对误差为主，研究目标约 1%，同时报告最大绝对误差；
- 透明、半透明、强反光、眩光和容器边缘分别统计；
- 报告 MAE、RMSE、95% 误差分位、拒绝率和视频抖动；
- 完成独立量具、照明、温度、多容器与重复性验证后，才能形成产品精度规格。

## 9. 是否必须测空容器底面

固定标尺模式不要求先由深度相机测空容器底面，因为透明/反光条件下底面深度也可能不可靠。零液深和米制尺度来自操作员提供的真实参考点。

CAD 模式的零液深来自 CAD 中的 level_origin_m，尺度来自 CAD 单位和相机标定。空容器底面扫描可以作为独立校核，但不是透明液深测量的唯一依据。
