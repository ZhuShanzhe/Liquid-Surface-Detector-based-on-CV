# 实际液深评价契约 v3

## 主测量量

本轮主指标是沿重力方向、相对水平容器底面的面积平均实际液深 H，单位米。
它不是相机轴向距离 Z，也不是双层液体中某一层的厚度。
不平整液面另外记录最浅、最深、P05、P95，不能用拟合平面中点替代全部波面真值。

当前实现范围：已知内参、相机到重力世界坐标的位姿、水平底面高度、容器在世界XY中的固定占地轮廓。
真实部署必须通过空容器／已知参照完成这些标定；不能拿本轮理想仿真标定精度承诺现场精度。
斜底、异形底和含内构件的容器尚未包含在本轮评价定义内，后续须明确液位基准或采用底面几何场。

## 推理与评价分离

推理仅输入RGB、以米为单位的原始轴向深度、内参、位姿、底面和轮廓标定。
模型预测液面掩码，不与真值掩码求交；反投影预测点、变换坐标，计算点的底面相对高度。
按10×10占地单元汇总中位点，四邻点IDW插值到均匀占地网格，再计算面积统计。
插值不是对未观测波面和隐藏层的正确性保证。

仿真真值由已知场景连续液面函数在相同均匀占地网格上计算，只进入评分和训练监督，不能进入推理特征、选点或接受门控。
离线真值几何自检允许将真值深度和掩码送入汇总器，结果必须单列，不得称为模型准确度。

本轮宽松研究门控要求64个预测支持点、至少4个空间单元、至少12%占地单元覆盖、正平均液深。
门控不校验液面身份和错误回波，因此接受不等于结果正确，更不等于生产安全许可。

## 固定指标分母

设全部输入帧数为N，接受输出数A，接受且真值可评估数E，误差处于容差内数G。

| 指标 | 定义 |
|---|---|
| MAE | E帧的平均绝对液深误差；毫米展示 |
| AbsRel | E帧上 mean(abs(H预测−H真值)/H真值) |
| P95绝对误差 | E帧绝对误差的95分位数，不平均多个子组分位数 |
| 每帧通过容差 | max(0.005m, 0.02×H真值) |
| 输出内通过率 | G/E |
| 输出覆盖率 | A/N |
| 可评估输出率 | E/A |
| 全帧有效通过率 | G/N |

无输出不记作零误差，E为零时误差和输出内通过率为null。报告必须同时呈现误差、通过率、覆盖率，不能只筛掉困难帧。
相机距离段与实际液深段分别统计；相机距离0.1—10m不能证明实际液深0.1—10m都已评估。

## 工程目标

| 范围 | AbsRel | 输出内通过率 | 输出覆盖率 | 可评估输出率 |
|---|---:|---:|---:|---:|
| 普通场景 | ≤1.5% | ≥90% | ≥95% | ≥99% |
| 支持的困难场景 | ≤3% | ≥75% | ≥80% | ≥98% |

这些是项目研发目标，不是法规、行业通用标准或软件著作权登记条件。
95%—100%严重失效仍不作为新增优化承诺；不可观测状态应拒绝或引入独立测量。

## 实验规则与复现

历史测试只重新评分，不用于选轮次。新测试在冻结权重后启封；不根据测试标签改阈值或反选模型。
直接液深微调的抽样按材料×相机距离×实际液深均衡；真实标签只用于训练抽样及损失。
验证选模同时考察容差归一化误差、尾部和材料分组覆盖／有效通过率防回退；允许第0轮原权重回退。

以下命令在服务器仓库根目录运行，结果文件须使用新的路径，避免覆盖历史证据。

```bash
PYTHONPATH=src /root/autodl-tmp/envs/liquid-depth/bin/python \
  scripts/evaluate_liquid_height_v21.py \
  --backend v17 --manifest /absolute/path/manifest.csv \
  --split test --output /absolute/new/path/height-evaluation.json

PYTHONPATH=src /root/autodl-tmp/envs/liquid-depth/bin/python \
  scripts/predict_liquid_height_v21.py \
  --rgb /absolute/path/rgb.png --raw /absolute/path/raw_depth_m.npy \
  --calibration /absolute/path/calibration.json \
  --output /absolute/new/path/prediction.json
```

推理标定JSON必须恰好包含intrinsics、camera_to_world_cv、bottom_z_m、radii_m、footprint_exponent五个字段，不能传真实液面或材质标签。
首轮残差校准头没有稳定改善，不建议启用`--head`。直接液深微调也未通过选模条件，保留原模型。
参见[统一复评与透明半透明实验报告](liquid_height_reassessment_v21.md)。
