# V14 多方法筛选报告

## 结论

已在服务器完成 4 类模型、10 个配置的冻结权重对照，另做 6 个配置的输入偏移测试。本轮没有微调模型，也没有改变生产默认配置。

1. **透明液体：优先研究 DFNet 的直接深度补全路线。** 正常输入下优势明确，但对尺度偏差很敏感，应先解决系统性偏差和误接受，再考虑替换 V12。
2. **半透明液体：保留 V12，并将整体液面拟合作为低成本改进分支。** 改善较小，系统性输入偏差仍未解决。
3. **LingBot-Depth 与 SwinDRNet：暂不作为本项目下一轮微调的优先对象。** 本次冻结权重迁移不理想，不等于否定它们在透明物体任务上的能力。
4. 没有方法达到可靠工业液深测量的结论。模型输出更完整，不能自动解释为更可信。

## 1. 为什么选择这些方法

| 方法 | 框架 | 本轮设置 |
|---|---|---|
| 原始深度 | 传感器直接测量 | 缺失点计入未恢复 |
| V9.1 单深度头 | RGB-D → 单一深度图 | 跳过四候选与排序，使用已有冻结主干 |
| V12 | 多候选 → 上下文排序 | 固定已有权重，不用置信度拒绝，用作深度本身的对照 |
| TransCG / DFNet | RGB-D → 深度补全 | 官方权重；原生 0.3–1 m、扩展 0.1–10 m 两种范围 |
| DREDS / SwinDRNet | RGB-D → 深度恢复 | 官方权重；默认最大 3 m、扩展 10 m |
| LingBot-Depth v0.5 | RGB-D 基础模型 → 深度恢复 | 完整预训练权重、默认 3600 tokens，无液面置信度筛选 |
| 单深度 + 整体拟合 | 单一深度 → 整体表面 | 预测掩码内进行 4 步稳健平面拟合 |
| V12 + 整体拟合 | 已选深度 → 整体表面 | 相同拟合方法；用于区分整体表面约束和此前的局部几何打分 |

“扩展范围”只修改输入/输出有效范围，保留网络权重、归一化、补洞等已有官方适配流程；它不是重新训练得到的广量程模型。

参考：[TransCG](https://github.com/Galaxies99/TransCG)、[DREDS](https://github.com/PKU-EPIC/DREDS)、[LingBot-Depth](https://github.com/Robbyant/lingbot-depth)。

## 2. 评估口径

- 开发集：旧验证集 fold 0，172 帧、68 个序列；此前已参与项目研究。
- 新测试集：新种子 20260915107，256 个独立场景。透明、半透明、多层、复合各 64 个；每类按距离区间各 16 个。
- 与原训练/验证清单及 V12、V13 新测试集的序列 ID 无交集。仍使用同一仿真器，不能代表真实设备与新物理模型的泛化。
- 所有模型冻结，不根据新测试集重新训练、调整阈值或选参数。
- 输入基准 320×180；各外部模型内部按自身输入约定缩放。RGB 反归一化、米制深度与有效性规则统一。
- 真值只用于评价；没有用真值选择候选、对齐尺度、生成推理掩码或拟合液面。
- 容差为轴向相机深度的 max(5 mm, 2%)，不是容器底面参考的最终液深误差。
- 主指标“正确恢复率”= 容差内正确像素 / 全部有效真值液面像素。缺失输出算未恢复；MAE 只在有输出的有效点上计算，必须结合覆盖率阅读。
- 同时输出统一预测掩码内的结果、原始深度缺失区域结果、距离分组、逐帧原始统计和大误差统计。
- 不评估各模型未经液面任务校准的置信度；本轮结果不能直接与 V12 原报告中经过置信度筛选的通过率、MAE 比较。
- 95% 区间采用 2000 次序列级成对 bootstrap；开发集同序列帧合并。多方法筛选属于探索性比较，未做多重比较校正。

## 3. 新场景主要结果

下表是全部有效液面区域的正确恢复率。V12、单深度、整体拟合、LingBot 的输出覆盖率均为 100%；DFNet 扩展范围在透明/半透明场景为 99.3%/99.9%。

| 方法 | 透明正确恢复率 | 半透明正确恢复率 | 透明 MAE | 半透明 MAE |
|---|---:|---:|---:|---:|
| V12 | 34.61% | 46.62% | 119.68 mm | 59.64 mm |
| 单深度直接输出 | 34.75% | 44.53% | 128.33 mm | 61.00 mm |
| 单深度 + 整体拟合 | 35.96% | 46.27% | 124.62 mm | 57.57 mm |
| V12 + 整体拟合 | 36.74% | **49.74%** | 115.43 mm | 57.12 mm |
| DFNet 扩展范围 | **54.13%** | 40.96% | **96.42 mm** | **38.87 mm** |
| LingBot-Depth v0.5 | 18.93% | 30.10% | 661.29 mm | 79.63 mm |
| SwinDRNet 扩展范围 | 3.96% | 6.35% | 1207.96 mm | 812.19 mm |

DFNet 原生范围的透明/半透明正确恢复率为 13.76%/8.68%，覆盖率仅 35.7%/21.8%；SwinDRNet 原生范围为 3.78%/5.94%。它们的原生量程无法直接覆盖本项目的整体测试范围。

原始传感器深度的透明/半透明正确恢复率为 25.45%/19.16%，覆盖率为 44.0%/64.1%。

### 优势是否稳定

- DFNet 扩展范围相对 V12：透明 **+19.52 个百分点**，95% 区间 **[+12.03, +27.22]**。
- V12 + 整体拟合相对 V12：半透明 **+3.12 个百分点**，95% 区间 **[+0.31, +6.10]**；透明 +2.14，区间 [-0.10, +4.55]，尚不能确认稳定改善。
- 单深度模型在开发集透明场景有优势，但新场景仅 +0.14 个百分点，区间 [-3.44, +4.03]。因此不能简单删除排序分支并宣布问题解决。
- LingBot 在透明/半透明场景分别下降 15.68/16.52 个百分点；开发集部分样本上的好表现没有稳定迁移。

## 4. 输入偏移是目前共同的弱点

固定将非零输入深度增加 5%，真值和 RGB 不变。以下仍为正确恢复率，不是拒绝后的精度。

| 方法 | 透明：正常 → 偏移 | 半透明：正常 → 偏移 |
|---|---:|---:|
| V12 | 34.61% → 19.08% | 46.62% → 12.88% |
| 单深度 | 34.75% → 13.74% | 44.53% → 8.20% |
| V12 + 整体拟合 | 36.74% → 17.72% | 49.74% → 11.77% |
| DFNet 扩展范围 | 54.13% → **4.28%** | 40.96% → **7.20%** |
| LingBot | 18.93% → 2.90% | 30.10% → 2.93% |

这说明 DFNet 的正常输入优势不能直接转化为可靠性优势。结果支持“依赖输入深度尺度”的判断，但不能仅凭这个实验把每个失败归因为折射或相机物理极限。5% 是人为压力测试，不是设备已测得的实际标定误差。

## 5. 哪些方向最值得继续优化

### 第一优先：DFNet 作为透明液体专用深度补全分支

理由：不再依赖离散候选池，在新场景和四个距离分组中都有值得研究的正常输入收益，推理成本可控。

下一轮重点：

1. 使用液面真值进行任务微调，明确区分液面、底面和壁面；透明物体预训练不能替代液面身份监督。
2. 训练中加入正负尺度偏差、局部错误回波、缺失和高光，按未见过的偏差幅度独立验证。
3. 把有效回波与疑似错误回波分开处理；不能把所有非零深度当可靠尺度锚点。
4. 增加可校准的拒绝机制，比较相同覆盖率下的错误率，并保留明显失配时的拒绝输出。
5. 正常性能与偏移性能同时满足约束后，再考虑替换或组合已有方法。

半透明中存在一个需要继续验证的分组现象：DFNet 在 0.1–0.3 m 的正确恢复率仅 6.09%，而在 0.3–1、1–3、3–10 m 为 52.85%、66.99%、62.76%。说明近距离失效值得单独排查。每组只有 16 个场景；分组使用真值距离作诊断，不能据此直接建立使用真值分流的运行时策略。

### 第二优先：V12 + 整体液面拟合

半透明场景有小幅收益，实现简单。应继续检查支持点空间分布、边界与弯月面、拟合残差，以及误接受到底面时的失败行为。

这条路线仍依赖前面的液面身份判断。平整的错误底面也会通过整体拟合；输入偏差测试没有显示鲁棒性收益，因此它适合作为辅助改善，不能替代误接受控制。

### 暂缓：LingBot 与 SwinDRNet 的大规模微调

本轮迁移效果与大误差风险都不理想。先做更多零样本或小样本针对性验证才有理由投入大规模训练。

SwinDRNet 在自身 DREDS 数据的 4 帧接口控制测试中，MAE 约 9.76 mm、输出覆盖率 100%，无运行失败；DFNet 在 TransCG 的 4 帧中 MAE 约 12.17 mm、覆盖率约 55.4%，无运行失败。这只能帮助排查接入错误，不能作为复现论文性能的证据。控制测试使用既有评价脚本的其他容差，未混入液面比较。

## 6. 其他框架的筛选结果

| 路线 | 本轮处置 | 原因 |
|---|---|---|
| 接触线 + CAD / 容器几何 | 保留，等待项目标定数据 | 项目已有相关分支；现有 DTLD 数据缺少完成毫米级验证需要的 CAD/内壁扫描与实际液深标签 |
| DKT 视频扩散 | 未纳入本轮定量比较 | 需要合适的视频、液面身份及尺度验证；现有单帧液面基准不能验证时序收益 |
| 底部图案 + 折射反演 | 值得设计专项采集 | 需要可见底纹与光学标定；本轮数据不具备对应受控观测，不能伪造可比结果 |
| NeReF 多视角折射重建 | 暂缓 | 需要带位姿的多视角及折射对应，不适合直接套用现有单帧基准 |

资料：[DKT](https://github.com/Daniellli/DKT)、[单相机液面 Schlieren 测量](https://arxiv.org/abs/2110.12744)、[NeReF](https://arxiv.org/abs/2203.04130)。

## 7. 运行与复现

- RTX 5090，PyTorch 2.11.0+cu128。模型主体热推理中位数：V12 4.33 ms，V12 + 整体拟合 6.47 ms，DFNet 扩展范围 42.98 ms，LingBot 43.82 ms，SwinDRNet 扩展范围 20.90 ms。
- 这些不是完整产品时延：不包含文件读取、统一掩码诊断开销、传感器采集及最终液深计算。不能据此直接宣布满足 500 ms 工业预算。
- LingBot 使用官方完整 v0.5 权重，SHA256 与官方 ModelScope 文件元数据一致；官方源码版本 f3a237e。未安装新依赖或替换现有环境。
- LingBot 的独立样本注意力通过 PyTorch 原生 SDPA 运行，保留各样本内部 RGB/深度 token；小型 FP32 等价性检查最大差异为 0。
- DFNet / SwinDRNet 遇到整帧原始深度全缺失时计为无法输出，不丢弃样本。
- 新增指标与平面契约测试，仓库全部测试 **218 passed，13 个既有 warning**。
- 代码与实验配置、模型哈希、逐帧统计、bootstrap、距离分组和测试日志随交付包保存。
- 服务器分支：codex/v14-multimethod-screen。默认生产模型未切换，未推送远端。

## 最终判断

**最有必要继续深入的是“液面任务适配的 DFNet 深度补全”，但第一道门槛是偏差鲁棒性与可靠拒绝。半透明场景保留 V12，整体拟合作为小幅改善分支。当前没有证据支持直接用更大的通用模型全面替换现有方案。**
