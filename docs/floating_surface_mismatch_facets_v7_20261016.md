# 漂浮物最高高度：失配检查、孤立峰约束与保边分片 V7

日期：2026-10-16。状态：完成训练、独立仿真对照及无 USB 接口验证；保留为可选实验版，不替换正式 V4 默认链路。

## 结论

V7 消除了已知的部分灾难性误接纳，并降低计算开销，但新独立集的整体精度没有超过 V4/V5。不能以“某个历史失败修复”代表整体提升，也不能只看通过率。尤其是 50–100 mm 误差占比由 V5 的 6.39% 升至 V7 的 18.89%。保边分片目前只解决部分局部形状表达问题，尚未解决“最高物体未形成候选”和“平滑但有共同测距偏差”。

正式默认配置、液深算法、旧版代码均不改动。视觉仅在 `floating_objects` 且显式开启时运行，只允许替换 `highest_height_m`；其他场景不得启用。所有帧保留数值输出，候选不通过时回退旧版，不删除难帧、不强制归零、不用容器沿截断最高高度。原有最高高度不得低于液面的物理顺序约束保持不变。

## 1. 改动与边界

| 项目 | V7 实现 | 仍然不能保证的事项 |
|---|---|---|
| 模型失配 | 三折空间留出；以传感器噪声归一化的 CV/残差硬检查；失配量加入估计区间 | 一致的测距偏置也可能很平滑，不能靠自洽性发现 |
| 孤立高峰 | 至少12个原始点、最小像素跨度；3像素网格内的空间支持；最高预测附近的原始见证点 | 网格不等于独立噪声样本；真实的微小尖峰也可能证据不足 |
| 保边分片 | 根据观测沿 x/y 的三段中位数坡度变化选择分割轴；有明显弯折才分为两片，各自拟合；通过检查的高片不与低片平均 | 不是通用曲面重建；对斜向、多曲率、尖顶和遮挡仍有限制 |
| 最高点计算 | 模型仅在真实观测像素坐标处求值；不生成新的独立“测量点” | 不恢复未观测到的物理尖顶，不保证每个真实峰都被保留 |
| 候选可信度 | 58维观测/几何特征，训练轻量候选可靠性分类器；复用既有像素网络 | 分类分数不是校准后的计量置信概率；属于漂浮物不等于属于最高物体 |
| 延时 | 候选包围盒局部特征、等价低开销连通域；最多拟合28个候选；平坦区域不分片；ToF直接旁路 | 回退可能仍需第二次视觉处理；结构光尾部耗时仍偏高 |

双目/结构光在逆深度域拟合，ToF 在深度域拟合。硬检查要求内点比例≥0.6、CV和中位残差不超过验证集选定的2或3倍噪声，最高点由至少3或4个空间格支持。原始回波校正候选也必须对其自身的校正高度检查见证点，而不是借用另一个曲面的支持。

## 2. 训练与独立测试协议

- 新增训练的是候选/模型可信度分类器，不是重新训练 RGB 像素网络。使用既有训练198组安装与验证99组安装，每组2帧；训练/验证种子分别为 `202610160317` / `202610160419`。
- 训练共20,020个模型候选，其中18,398个正例。监督要求漂浮物像素与真实漂浮物回波占比均≥55%，并且模型高度接近其匹配的可见漂浮物连通区域顶部，容差为 `max(50mm, 5%顶部高度)`。仅训练/验证阶段使用这些离线标签。
- 参数选择只使用验证集，冻结代码、权重、策略 SHA256 后才评估新测试集；测试集种子 `202610162711`，198组独立安装、396帧，含360帧真实可见漂浮物和36帧干槽对照。
- 360帧按液深分10层，每层36帧：0.01–0.1、0.1–1、1–2……8–9 m；三类传感器各120帧。相机到底面≤10 m。每组2帧共享安装条件，不能当作两个完全独立安装。
- 测试是相同渲染器/生成分布下的新随机种子，并非跨仿真器泛化或真实工业相机验收。立体/结构光/ToF为现有传感器代理噪声模型，不应宣称已验证真实硬件。
- 同一帧分别运行 V4、V5、V7检查版和V7完整策略，全部经过相同的最高高度输出隔离层。推理完成后才读取离线真值与标签。校准失败先修复标注输入，再测量，不按输出误差筛帧。
- 验证集选定：ToF旁路V4；双目为原始校正与表面候选混合；结构光为表面候选。检查版只允许带检查的原始校正候选，但其阈值独立经验证选择，因此不是单一开关完全等参的因果消融。

最高高度是真实物理网格最高点相对容器内底面的高度，不是相机距离，也不是漂浮物露出液面的高度。最高高度通过容差 `max(50mm, 5%真实最高高度)`；液深使用 `max(20mm, 2%真实液深)`。相对误差分母分别为各自真实高度；空槽不计算相对误差。

## 4. 实际采用与失败原因

V7在360帧中203帧采用新候选，157帧旁路或回退；203帧里最终最高候选分别为局部分片85、全局表面77、带检查原始校正41。最终候选最高附近见证格数中位数19，但这不是19个独立传感器测量。采用新候选的最大误差225.54 mm，回退最大434.15 mm。

逐帧与V5相比：改善超过5 mm的72帧，退化超过5 mm的153帧，其余135帧差异≤5 mm。分片不是无代价的精度提升。

### 4.1 候选缺失后仍回退到有偏旧结果

新集结构光 case477 repeat1：真实最高2.729283 m，最终高估434.15 mm。80个候选中只有2个满足进入拟合的点数/分数条件，没有因为28候选算力上限漏掉其他合格候选；拟合产生4个模型，但可信度均很低（约0.01–0.12）。repeat0没有满足拟合入口的候选。最高点在理想渲染深度中实际可见，因此不是物理遮挡就能解释；观测回波、像素候选形成及可信度仍不足。新模型未采用，旧回退错误保留。约束新分支并不会自动修复旧回退。

case639（新集，非历史同号场景）和case219也有真实漂浮物回波比例100%的局部候选，但校正后的高度及候选可信度不支持采用，最终回退仍高估约249–295 mm。语义正确不等于测距正确。此处不能只放宽模型门槛，否则会放入同样光滑的错误高度。

### 4.2 识别到的是较低物体，不是把同一最高物抹平

结构光case315 repeat1：真值4.900878 m，理想可见最高4.899058 m；获选全局片高度约4.675 m，误差225.54 mm。候选语义与回波来源比例均100%，但其匹配连通区域的可见顶部仅约4.67 m。也就是说，高置信候选是另一块较低的漂浮物；最高物体没有赢得候选竞争。局部分片无法凭空补回未入选的最高实例。repeat0存在约4.89 m的原始校正候选，但结构光验证策略选择了表面模式，未采用该原始校正候选。该选择也是明确的策略局限，不能只归因于相机。

### 4.3 有最高物体证据，仍有平滑的共同偏置

双目case507 repeat1：真值5.240557 m、可见顶5.234552 m；带检查原始校正候选约5.068 m，低估172.75 mm。其漂浮物像素/回波比例100%，CV约0.71倍噪声，最高附近有48个网格见证。可见“拟合自洽、来源正确”仍不能保证绝对顶部正确；q90校正、测距偏置和未恢复尖顶的统计效应没有被失配检查消除。

此外，训练的二元正例定义在约5.2 m时容许约260 mm误差，172 mm仍可成为“合格候选”。因此分数接近1并不意味着毫米级精度高。这直接解释了为什么通过率尚可，MAE却变差。后续应训练连续误差风险与相对顶部排序，而不是仅以宽容差内/外作为可信度监督。

## 5. 延时、液深不变与验证

同一新集有漂浮物帧的算法耗时：V5中位478 ms，V7中位283 ms，降低约41%；P95由581降至508 ms。V7检查版P95为485 ms。完整策略P95仍略超0.5 s，结构光单类P95约568 ms，因此不能宣称严格满足所有帧的0.5 s预算。

延时是GPU预热、模型常驻后的一次`measure`调用，包括最高高度输出隔离层和回退计算；不包含相机采集、磁盘读取、UI刷新、进程启动或模型冷加载。固定顺序V4→V5→检查版→V7，并非随机交叉的硬实时基准。设备为服务器RTX5090，CPU线程按脚本限制。

四路共1,584条测量记录中，液深相对V4变化数为0。360帧液深MAE23.12 mm、P95 86.26 mm、容差通过率89.44%，四路完全相同；这不是本次提升的指标。无USB入口验证覆盖开、关、检查版及其他场景持不存在模型路径的情况，均通过；其他场景未加载视觉模型。全套测试674项通过、14条原有警告。新增候选加速与V5参考实现的掩码及特征一致性测试通过。

全套测试从仓库根目录以 `PYTHONPATH=src:scripts OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=4 /root/autodl-tmp/envs/liquid-depth/bin/python -m pytest -q` 运行。一次省略`scripts`搜索路径的复查在收集旧测试时出现`capacity_priors_v28`导入错误；修正调用环境即可，无需修改旧源码。该失败调用日志也保留，不计作模型失败或已通过的测试。

保边形状单元测试使用无噪声折脊，能保留约0.8 m顶点且误差≤15 mm；这是算法性质检查，不是新独立RGB-D集的全面尖顶准确率证明。

## 6. 下一步建议与使用方式

1. 保留V7硬失配与孤立峰检查用于后续组合实验，但不整体推广本版策略。先解决最高实例候选完整性、低物体高分竞争，再决定是否启用局部分片。
2. 可信度拆为“物体/回波真实性”和“连续高度误差风险”，并加入同帧候选的顶部排序。最高点与主体形状分开预测，训练可见尖顶/小最高实例的困难负例，不能仅监督宽容差事件。
3. 对共同测距偏置单独建模。空间CV只能检测不一致，不能替代测距偏置标定；需要原始高度、校正高度、局部分片之间的可解释比较与可靠锚点，不以模型自洽当作绝对准确。
4. 回退不是安全证书。保留全输出要求，同时给出“新模型否决后使用旧结果”的状态与风险；后续再比较多帧证据，不用删帧提升通过率。
5. 优化只在训练/验证上进行，新的策略必须换另一独立种子测试，不能据本测试集选择按量程/传感器最佳版本后再把拼接结果称为独立成绩。

从仓库根目录使用 `scripts/measure_surface_v7.py`，传入空槽建模bundle、空槽深度、当前深度、对齐RGB，显式设置 `--scene floating_objects --enable-floating-peak-vision` 才启用本实验版；`--guards-only`用于检查版。配置为 `configs/floating_surface_v7.json`。正式 `configs/application_route.json` 保持原样，V4/V5/V6及确定版对称几何快照保留。
