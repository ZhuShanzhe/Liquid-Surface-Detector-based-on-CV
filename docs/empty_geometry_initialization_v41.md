# 空槽图像与少量实测参数的容器几何初始化

日期：2026年10月12日。

固定机位、底面可见的规则容器，可以使用一帧空槽 RGB-D 图像、一个独立米制参照和容器内高建立简化几何，不必提供 CAD。本实现已接入普通漫反射液面 V40 实验链路，并提供透明与轻度半透明五帧先验链路的显式适配接口。它不替代相机内参标定，也不把单张 RGB 照片当作可信的三维模型。

新方案不会替换现有默认标尺流程。测量输出保留有符号候选液深，但 `accepted=false`、`liquid_depth_m=null`，直到完成独立现场验收和机位有效性检查；不得直接用于闭环工业控制。

## 最少需要哪些信息

| 输入 | 获得方式 | 用途 |
| --- | --- | --- |
| 一帧确实为空槽的图像和深度 | 相机采集，深度与选点图像配准且已去畸变 | 估计底面方向，保留空槽噪声参照 |
| 对应相机内参、实际双目基线和深度单位 | SDK 或实际标定文件，不能用猜测值 | 反投影、视差模型和单位换算 |
| 底面完整内边界 | 圆形或椭圆选6至12点；矩形选四角 | 拟合内轮廓和容器范围 |
| 一个独立米制参照 | 底面上两点间的实测长度，或相机光心到底面的实测垂直距离，二选一 | 确定几何尺度及底面位置 |
| 容器内部高度 | 实测内部底面至开口的高度 | 推得开口范围，限制取样区域 |
| 另一条独立底面长度，推荐 | 选择另一组两端点并实测长度 | 检查尺度与形状，不能重复用拟合参照 |
| 独立重力方向，工程接口可选 | 已标定 IMU 或安装测量换算到相机坐标系 | 减少空槽点云噪声造成的法向偏差 |

仅用相机原始底面深度做自己的米制参照，会把底面测距偏差当成真实几何。因此原始深度距离不自动成为几何锚点。尺度线必须位于底面，不能用容器外壁尺寸、斜边或漂浮物代替。垂距不是镜头外壳至底面的斜距，需考虑光心位置和安装姿态。

两个数值并不是一套完整相机标定：最低人工参数是“参照长度或底面垂距”及“容器内高”，此外仍需 SDK 参数与边界选点。独立校核线再增加一个实测长度，更适合高精度用途。

## 操作流程

1. 固定相机和容器，确认底面水平平整、侧壁竖直，空槽没有残液。采集空槽帧；保存 `rgb.png`、`depth.npy` 和包含内参的 `depth_info.json`。
2. 打开现有工业面板，进入“空槽几何初始化（调试）”。载入空槽帧后，该帧路径固定用于此次建模，后续新采集帧不会替换空槽参照。
3. 选择圆形、椭圆或矩形，标记内底面完整边界。选择底面尺度线并填入实测长度，或填写光心到底面的垂距；填写内部高度、实际基线和深度单位。
4. 推荐再选一条不同方向的底面校核线。确认空槽、水平平底、固定机位、去畸变配准四个条件，预览模型。黄色是底面，绿色是根据内高推得的开口；核对其与实际容器是否一致。
5. 保存为一个新的 YAML 方案。旧方案和已有标定资产不会覆盖。加入液体后读取最新帧，可查看候选液深及诊断；修改几何参数或选点后，必须重新预览和保存。
6. 用未参与建模的多个已知液深独立验收，覆盖空槽、浅液位和较高液位。移动相机、改变焦距分辨率、重新配准或改变容器后重新标定。当前只有内参和图像尺寸变更自动报错，真实机位变化还需人工确认。

远距离使用尺度线时，尽量选取可清晰定位的长线段；实现要求尺度线和校核线至少20像素。不要通过插值放大图像绕过这一要求。底部严重遮挡、不可测或只有很短弧段时，本入口不生成虚构几何；补拍可观测视角，或采用独立几何标定、CAD 等其他流程。多视角自动配准建模尚未实现。

## 几何和测量如何连接

空槽底面内部的逆深度先经过随机采样稳健拟合和迭代加权，估计平面方向。一个独立尺寸或底面垂距锚定米制距离；底面边界射线与该平面相交，再拟合圆、椭圆或矩形。底面中心定义为容器坐标系原点，底面法向定义为向上的轴；由实测内高推得开口平面。

没有独立重力信息时，底面法向依赖“底面确实水平”的假设，并记录 `no_independent_gravity_check`。独立重力接口是 `geometry.up_camera`，需提供相机坐标系下指向上方的三维单位方向；与底面估计相差超过8度时报错，不自动融合明显冲突的信息。

几何生成 `HeightCalibration`，普通链路用它建立容器内缩取样范围，并将同一空槽帧作为 V40 公共偏置和空间残差参照。后续深度图经过既有去噪与稳健估计，输出相对内部底面的液深。空槽的正负测量误差和超出名义范围的数值仍保留，不强制归零、不裁剪。

矩形容器的计算取样范围使用16次超椭圆作保守内缩近似，预览则显示矩形角点；不等价于任意多边形或完整实体 CAD。实测内高用于几何范围，不作为预测值裁剪上限。

## 透明与半透明链路

生成几何可通过 `make_refraction_meter` 显式传给已有 `FivePriorImageMeter`。这只是复用几何，不取消“1帧空槽＋4帧不同已知液深”的光学校正预算。仍需各帧原始、校正后的左右目灰度或红外图像、各自有效底纹 ROI、真实左右目内参和基线。

```python
from liquid_depth.empty_geometry_v41 import make_refraction_meter

meter = make_refraction_meter(
    bundle, right_intrinsics, masks, prior_images, known_heights,
    condition='transparent',  # 或 translucent_mild
    left_intrinsics=left_intrinsics,
)
result = meter.measure(current_left_right_images)
```

`known_heights` 依次为零和四个不同的正液深；`prior_images` 的每个元素及测量输入都包含 `left`、`right` 两张原生灰度图。左右 ROI 分别指定，不能把 RGB 图上的掩码盲目复制到红外左右目。

现有透明求解器仅支持近乎垂直的校正双目几何，本适配器要求倾角不超过0.5度、左右焦距兼容，且建模内参必须等于实际校正后左目内参。RGB 对齐深度图与红外左目坐标系不一致时，不能直接导出；需先把空槽深度和选点图像正确变换到左目坐标系。任意倾角的折射、侧壁折射、ToF 多路径和强散射不在此适配器中自动解决。

透明接口的几何传递与输入保护已测试；本次新增几何的误差试验针对普通平面链路，不把其数字宣称为透明液体的端到端精度。透明链路也未自动启用到工业面板默认路由。

CLI 与面板调用同一保存和计算实现。在项目根目录设置 `PYTHONPATH=src` 后运行：

```bash
/root/autodl-tmp/envs/liquid-depth/bin/python scripts/setup_empty_geometry_v41.py \
  --frame /实际采集目录/空槽帧 \
  --spec /实际标定目录/人工几何输入.json \
  --profile /实际标定目录/新的空槽方案.yaml \
  --depth-scale-to-m 0.001 \
  --measure-frame /实际采集目录/液体帧 --output-dir /实际输出目录
```

`--spec` 对应面板发送的 `geometry` 对象。主要字段为 `shape`、`bottom_outline_px`、`wall_height_m`、`baseline_m`、`metric_anchor`、`check_spans` 和四项确认。锚点形式为 `{"kind":"span","pixels":[[u1,v1],[u2,v2]],"length_m":实测米值}`，或 `{"kind":"perpendicular_distance","distance_m":实测米值}`。图像坐标用像素，物理值用米；不要混用单位。

## 适用边界与验收

当前适用固定顶部相机、可见平整水平底面、竖直凸侧壁的圆形、椭圆或矩形容器，以及正常漫反射液面的可靠表面返回。锥形、阶梯或曲面底部、不可见底部、非竖直侧壁、持续移动相机和多层透明侧壁，不靠少量参数自动恢复。

拟合至少要求128个有效底面点、底面内部15%的有效深度和足够空间分布。独立尺寸偏差超过 `max(3 mm, 2%×实测长度)` 会报错；这是发现几何不一致的粗校核，并非工业液位精度保证。校核失败不自动改变实测值，也不在评估中删除相应测量帧。

预览和保存还会检查普通链路取样范围内是否有可用空槽参照，防止保存出几何形式合理却无法初始化测量的方案。该范围同时受底面、开口和估计姿态影响；深容器、开口紧及底面法向估计偏差组合时，可能没有足够共同可观测区域。

应用验证仍以相机到底面距离不超过10米为范围；程序不以10米硬切正常数值。几何尺度、空槽法向、噪声随时间变化和真实液面回波质量都可能影响精度。单帧空槽不能识别任意测距非线性，更不能证明液体状态下仍有可靠表面返回。

## 独立仿真验证

最终验证使用独立随机种子202610124409，共128组容器配置，圆形、椭圆和矩形交替采样。每组包含正常及较差噪声两种条件，各4次液面测量，共1024个测试观测；三个方法合计3072条结果，不是3072个独立场景。每个方法共享同一空槽及测量观测，基线使用真值几何作为理想参考，而两个拟合方案只使用空槽观测及带误差的人工参数。

原生分辨率为1280×800，沿用 V38 假定相机噪声。边界和参照端点选点误差标准差0.3像素，长度和内高实测误差标准差为 `1 mm + 0.1%×长度`，没有额外独立重力输入。此试验是几何平面与假定传感器噪声，不是完整 RGB/IR 光线追踪，也不是实体相机验收。空槽与测量帧的空间噪声保持稳定，不能推广到已知会退化的空间噪声大幅漂移条件。

误差以相对内部底面的实际液深计算。下表 MAE 仅对数值输出帧统计；数值输出率以全部测试帧为分母。诊断通过率使用 `|误差|≤max(5 mm, 2%×真实液深)`，未输出视为不通过。数值输出率不等于生产有效输出率，新方案的工业有效标志始终为假。

| 噪声条件与液深分组 | 理想几何 MAE mm | 尺度线建模 MAE mm | 垂距建模 MAE mm | 尺度线与垂距数值输出率 |
| --- | ---: | ---: | ---: | --- |
| 正常，0至9米均匀液深，288帧 | 0.32 | 14.87 | 6.06 | 均为100% |
| 正常，远距离浅液位，128帧 | 1.55 | 3.66 | 1.93 | 均为100% |
| 正常，5至100毫米近零液位，48帧 | 1.44 | 1.42 | 1.43 | 均为100% |
| 正常，空槽，48帧 | 1.15 | 1.14 | 1.14 | 均为100% |
| 较差，0至9米均匀液深，288帧 | 0.49 | 18.53 | 6.37 | 均为94.44% |
| 较差，远距离浅液位，128帧 | 2.39 | 4.31 | 2.46 | 均为96.88% |
| 较差，5至100毫米近零液位，48帧 | 2.20 | 2.22 | 2.14 | 均为100% |
| 较差，空槽，48帧 | 1.86 | 1.80 | 1.80 | 均为100% |

正常噪声均匀液深分组中，两种拟合方案的诊断通过率均为100%，但 MAE 显然不同，不能只凭通过率认定精度相同。较差噪声下，该分组尺度线通过率94.10%，垂距94.44%；对应有输出帧的绝对误差 P95 分别为64.33和17.79毫米。远距离浅液位较差噪声下，尺度线通过率89.84%，垂距93.75%。完整绝对及相对误差区间分布保存在 `summary.json`；空槽相对误差不定义。

尺度线方案和垂距方案各20帧未输出，其中尺度线16帧因共同可观测空槽点不足、4帧因独立尺寸校核失败；垂距分别为12和8帧。它们分别源于同一次初始化失败后对应的4帧，而不是20次独立失效。失败全发生在较差噪声条件，已保留在全帧分母，不通过放宽尺寸校核、强制归零或裁剪来提高指标。

可行性结论是：少量实测参数能替代规则容器的手工 CAD 几何输入，但不等于理想几何标定。尺度线的点击误差、长度误差与底面法向误差会改变底面尺度；该误差随液深增大更明显。实测垂距直接锚定底面位置，在本次两批独立测试中更稳定，应作为精度优先选项。远距离或深容器建议补充独立重力信息，并检查开口与底面共同可观测范围；若仍不满足，不生成工业有效测量。
