# 小漂浮物识别与最高高度尾部误差优化

日期：2026-10-15。范围：仿真研发，不是现场计量验收。

本轮新增可选区域验证链路，改善了漂浮物最高高度的平均误差、P95和通过率，并显著减少普通及眩光场景的假漂浮物接纳。液深仍使用固定对称几何，396帧逐帧一致。小于4像素的目标、结构光最高点的过度修正以及不平整液面上的连续错误回波仍需处理，视觉模块继续默认关闭、按需启用。

## 版本与应用边界

封存的对称几何确定版和上一版可选视觉链路均未修改，交付时分别核验原始源码哈希。新增入口为 `liquid_depth.float_evidence_v3.OptionalFloatMeterV3`，配置为 `configs/optional_float_v3.json`。

- `off`：不加载、执行视觉网络；液深保持固定对称几何，最高高度保持原几何包络。
- `auto`：显式启用RGB-D辅助；可信漂浮物提供最高高度，否则保留原几何最高高度，不拒绝整帧数值。
- 透明/半透明继续使用原五帧先验折射链路，本轮不合并、不重测。
- 远距浅液位另行标注留存，本轮全帧成绩仍包含这些帧，没有通过排除它们提高结果。

当前推荐已知漂浮物场景按需试用，眩光和低照可开展受控试用；普通场景可直接关闭以节省延迟。不平整液面最高高度存在退化，暂保持几何链路，不因本轮其他指标改善而统一开启。

## 改进方法

### 多尺度特征与原始深度分离

网络同时处理原图和四个重叠局部视图，局部图像放大后提取特征，再映射回原始像素网格。浮物语义、回波来源和米制可靠性仍分别输出。此操作没有创造新的测距采样点，所有高度计算只读取原始深度。

训练增强小目标和困难负样本，并对被误判成漂浮物的非漂浮物像素追加损失。扩大候选发现范围后，裸语义分割会产生更多碎片，因此不能直接拿语义掩码计算最高点。

### 区域验证与噪声相关最高点修正

新增区域分类器，使用连通性、紧致度、容器边界距离、候选与周围液面的深度差、噪声归一化残差、RGB对比、回波来源、可靠性等观测特征，判断候选是否为真实浮物。它不是把几项相关网络分数相乘后直接当作正确率。

另训练最高点偏置修正与条件分位数模型。分位数跨度包含上下分位数及中位预测，防止分位数交叉产生虚假的零不确定度。跨度过大或区域分数不足时回退几何输出；不会强制归零、裁剪液深或剔除困难帧。

验证集选定区域分数阈值0.7、跨度预算系数2.0。区域分数不是计量正确率，条件分位数跨度也不是已经证明覆盖率的现场置信区间。

## 数据与独立测试

新生成594个训练/验证安装场景，按安装划分训练396、验证198，每个安装两次深度采样；增加3–12像素小物体的比例，同时保留较大物体和普通、眩光、不平整等负样本。使用完整浮物视差噪声、量化及随机容器余量设置。训练种子为 `202610155361`。

在上一版权重上微调18轮，仅根据验证集选择权重；继续使用已有160个公开水面孤立障碍物弱标注图块作为外观先验，没有把它们当成米制液深监督。区域分类器使用16,653个训练候选，其中624个正候选；测试数据不参与分类器训练和阈值选择。

另生成198个全新安装、396帧，种子为 `202610155927`。普通、低照、眩光、漂浮物、不平整、部分丢失各66帧，包含主动双目、结构光和ToF代理，液深按空槽、浅液位及逐米区间至9m采样，相机到底面不超过10m。两次采样共享安装和RGB，不是独立的运动视频；统计重采样以安装为单位。

所有帧均保留。对照为上一版 `v2_auto`、纯几何 `v3_off` 和新版 `v3_auto`。表中的优化前后均来自这批相同新数据，不能拿上一轮不同种子的数值直接相减。

- 液深容差：`max(20mm, 2% × 真实液深)`，相对真实底面。
- 最高高度容差：`max(50mm, 5% × 真实最高高度)`，包含浮物，仍相对底面。
- 通过率分母为全部对应帧；数值输出率不是精度通过率。
- 本轮各模式液深和最高高度数值输出率均为100%。

## 剩余尾部误差的原因

1. **结构光偏置修正仍可能过强。** 测试安装747的最高真值6.814m，候选原始分位值6.772m，修正后反而变为6.623m，误差从约42mm扩大到191mm。该真实最高对象约896个可见像素，868个在容器ROI内，并非单纯点数不足；问题主要在噪声偏置与物体形状混淆后的过度修正。
2. **最高实体可能被整体拒绝，而低位实体通过。** 安装645为ToF，最高对象222个可见像素，其中215个在ROI内；候选覆盖182个，但区域分数约0.065，低于阈值。其候选高度自身也偏高，不能仅靠降低门槛解决。最终只接纳了较低物体，最高高度低估约127mm。需要改进候选拆分、形状上下文及区域收益判断，而非归咎于硬件缺少采样点。
3. **连续错误回波仍能伪装成真实浮物。** 不平整安装790没有真实浮物，存在1,479个有效的连续错误回波像素，新版误接纳高置信区域，将正确附近的几何最高高度抬高约0.25m。局部连贯性和网络高分不等于真实界面，仍需更多此类负样本或跨帧/独立成像证据。
4. **原几何回退自身仍有极端误差。** 安装640为远距浅液位，未接纳任何浮物，最高高度误差约781mm，来自保留的几何包络。它仍在全帧统计中，按既定安排留到远距浅液位统一优化。
5. **极小目标与未采样顶点仍受可观测性限制。** <4px目标只有2/24被最终接纳。局部放大增加可学习特征，无法恢复原始传感器从未测到的真实顶点；同时更大目标的漏接纳和过修正表明，当前不足也不能全部解释为物理极限。

按安装进行1,200次配对重采样后，漂浮物P95变化的95%区间约为−160至+49mm，眩光约为−244至+105mm；每场景只有33个安装，尾部样本仍少。观察到的P95改善不能当成已证明所有新分布都稳定改善。

本轮不根据上述独立测试继续调整阈值。下一轮应针对最高物体漏接纳、结构光过修正和连续假回波另建训练/验证数据，锁定规则后再测试新的安装集合。

## 延迟与使用

服务器RTX5090、480×270回放的新版`auto`算法延迟：中位163.35ms，P95235.15ms，最大387.81ms；`off`中位50.22ms。此测量不含相机曝光、采集、USB/网络传输和界面刷新，不能当成现场端到端保证。

```bash
cd /root/autodl-tmp/Liquid-Surface-Detector-based-on-CV
export PYTHONPATH=src:scripts
/root/autodl-tmp/envs/liquid-depth/bin/python scripts/measure_float_v3.py \
  --bundle /path/to/calibration.json --dry /path/to/dry_depth_m.npy \
  --depth /path/to/current_depth_m.npy --rgb /path/to/current_rgb.png \
  --profile configs/optional_float_v3.json --visual auto
```

不使用视觉时设置`--visual off`，默认也是关闭，无需RGB和模型。输入深度为米，RGB、深度和空槽参考必须对齐、标定一致。无USB回放样例在交付目录中保留，现场相机需由原采集模块提供输入。
