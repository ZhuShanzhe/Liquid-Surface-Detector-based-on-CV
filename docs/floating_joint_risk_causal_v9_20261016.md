# 漂浮物最高高度的硬支撑联合风险与多帧确认实验

日期 2026-10-16。版本 V9。范围限于固定相机、已标定容器、普通漫反射液体上漂浮物的最高高度；视觉不用于液深，不扩展到其他场景链路。正式默认配置保持原样，本版独立保存。

## 方法

V8的主要反例是高置信的错误小区域被误认为最高漂浮物，而条件高度风险只在真实漂浮物候选上训练，不能覆盖身份本身错误的情况。V9恢复空间硬证据，把错误区域与错误回波纳入整帧最高高度的联合风险监督，并为证据稀少的小候选增加因果多帧确认。

| 检查 | V9要求 |
|---|---|
| 常规单帧空间支撑 | 原始点数≥12，两个像素方向跨度均≥2，至少3个3像素空间格 |
| 拟合失配 | 复用V7传感器域平面拟合与三折空间留出，CV和中位残差≤3倍噪声，内点比例≥0.6，模型最高附近有≥3格支持 |
| 校正高度见证 | 额外检查校正后的实际候选高度附近，是否有≥3个原始观测空间格，不能借用另一平面的证据 |
| 小候选例外 | 仅限4–11点、二维包围盒至少2×2像素、≥2格；身份分数≥0.995，联合风险≤min(80mm,max(20mm,2%预测高度))，且原始语义/回波/可靠性均值≥0.5 |
| 多帧确认 | 小候选须在验证选择的2或3个不同深度曝光中匹配；像素重合比例≥0.5，高度差≤max(15mm,2%预测高度) |
| 记忆边界 | 只用过去帧及当前证据；最多3个历史帧、最大年龄0.5s；流切换、时序倒退、重复编号、过大间隔、缺少元数据重置或禁用确认；相同深度缓冲不累计票数 |

空间格不等于独立噪声样本。小候选的多帧通道也不声称恢复了充分二维曲面几何，它是严格风险筛选后的重复观测确认。大候选未通过拟合检查，不能以“小候选”身份绕过检查。最多检查排序前8个常规实例以限制计算量。

仍使用V8固定的连续高度校正头和已有RGB-D像素网络。本次新增71维联合身份与风险模型，特征为V8观测上下文、校正量、预测高度、原条件风险及实例差。训练46,083个候选，其中15,957个真实漂浮物候选、30,126个错误区域或错误回波候选；小错误候选的身份分类权重提高至4倍。新的90%分位风险目标是所有候选到真实整帧最高高度的绝对误差，包括身份错误和较低实例，不再为错误区域虚构一个“局部顶部”或把它排除。风险值非负映射不作用于测量高度，不做高度裁剪或强制归零。

风险训练仍用按安装分3折留出的新增校正预测，避免用校正头自身拟合误差冒充泛化误差；上游V8模型固定，并不是全部上游重新嵌套交叉训练。分类分数和分位风险均须独立检验，不等于安全保证。

身份监督沿用“主导可见漂浮物连通区域≥60%、真实漂浮物回波≥60%”的定义，负候选也包含混合区域，不应把30,126个负候选全部称作某一种物理错误回波。实例仍以连通区域近似，非物体ID级分割。联合风险把“局部高度虽正确、但来自较低物体”的候选也视为不适合输出整帧最高高度。

## 数据和独立评估

训练来自V8既有训练种子`202610160317`，不使用V8测试帧训练或选参。新验证种子`202610164119`与新测试种子`202610164913`各99组安装、每组4次深度曝光，共396帧。参数只由新验证集选择，测试前冻结代码、权重和策略SHA256。

每个短序列的场景、相机和RGB固定，深度为4次独立噪声曝光，采集时间戳按0.1s间隔。它验证固定场景中的因果确认，不是动态漂浮物、波浪运动、相机运动或光流对齐的验证。每组4帧相关，同一安装是统计重采样单位；不能把396帧称为396个独立安装。四帧所用传感器噪声仍是已有双目/结构光/ToF代理，不是实机漂移和多径的完整模型。

液深覆盖0.01–0.1、0.1–1、1–2……8–9m及干槽，三类传感器均衡，相机到底面≤10m。输入为同一空槽建模链路和模拟带噪操作标定。推理不读当前帧真值、分割标签或真实容器参数。所有冷启动、回退和超标帧保留，不以误差删帧。

最高高度是相对容器内底面的物理网格最高点，容差`max(50mm,5%真实最高高度)`；液深容差`max(20mm,2%真实液深)`。相对误差以对应真实高度为分母，空槽不计算相对误差。

主对照为V4、V5、V8主策略、V9同策略单帧版和V9因果多帧版。V8主策略的ToF/结构光沿用V5，不能把它们当作V8研究模型；V8研究策略只在历史异常诊断中单列。每帧方法顺序循环轮换，模型和CUDA预热；计时包含完整`measure`算法调用，但不包含模型加载、磁盘读取、相机采集和GUI。

验证集选定ToF身份门槛0.8、风险上限80mm、风险排序权重1、2帧确认；双目为0.8/250mm/0.5/2帧；结构光为0.8/80mm/0.5/3帧。验证集实际采用多帧小候选6次，均在ToF；双目、结构光未出现该通道的最终采用，不能据此声称所有传感器的小漂浮物均已解决。

同策略单帧与多帧对照可隔离确认机制的作用；V8与V9单帧之差同时包含硬约束和联合风险变化，不能据此单独归因于某一个模块。

## 使用边界

多帧只确认当前仍存在的候选，不在当前没有证据时输出历史最高高度。重复出现也不是正确性的证明，持续的错误墙面或回波还需由联合风险及身份模型识别。

部署需提供稳定的`stream_id`、递增`frame_id`及以秒为单位的采集时间戳。相机重定位或重标定应切换流或重建测量对象。未提供这些字段时，多帧确认禁用，仍可进行单帧估计并回退输出，不自动伪造帧编号。

所有帧立即输出当前估计或旧V4回退，不为了等待确认停住数值输出。采集时间0.1s不代表部署处理延时；若实际有效帧间隔超过0.5s，确认记忆会重置。冷启动先回退，达到条件后才允许小候选接管。

## 为什么恢复硬约束后仍然退化

360帧中V9有29帧超过最高高度容差。离线真值仅用于事后归因，不进入推理：

| 超标类别 | 帧数 | 现象与原因 |
|---|---:|---|
| 候选未接管，回退V4仍超标 | 19 | 联合风险、身份或硬约束拒绝候选；回退可保数值输出，但不能恢复已漏掉的最高物体 |
| 选中了较低漂浮物 | 7 | 区域确为漂浮物，但不是全帧最高实例；风险排序仍未稳定区分最高实例与更大、更可靠的低物体 |
| 错误区域或混合回波 | 2 | 共同偏差可以空间平滑、具有多格支撑；并非所有错误都是孤立尖峰 |
| 最高实例识别正确但测距超标 | 1 | 原始回波随机/共同偏差与连续校正残差仍存在，视觉身份正确不能保证米制高度正确 |

1. 最大误差来自结构光case459/repeat0：−322.96mm，身份通过候选8个，但风险通过0个，最终沿用V4；并非新模型生成了322.96mm的新高峰。case261/repeat3也因风险拒绝全部候选而低估266.96mm。风险头提升了谨慎程度，但没有改善回退链路，也不是全输出的风险保证。
2. 结构光case27/repeat2是硬约束与正确校正冲突的明确例子：V5/V8误差1.34mm，V9回退后173.09mm。381点候选CV=3.53σ、残差3.10σ，被局部平面失配拒绝；其他校正至真实顶部附近的候选，在校正后高度附近缺少原始点见证而被拒。校正的目的恰好可能是移除共同测距偏置，要求校正值必须贴合偏置原始点，会误拒有效修正。不能简单撤销硬证据，但应区分原始空间形状支撑和经独立标定支撑的共同偏差。
3. 全部常规实例检查共1265次：空间支撑不足1次、模型失配289次、校正高度无见证438次、支持通过537次。这是候选检查次数，不是帧数、误拒次数或独立样本数。当前局部平面约束对曲面、保边分片及共同偏差仍过于粗糙；只增加最小点数不是主要改进空间。
4. 主动双目case417/repeat2接管了较低物体，误差−227.31mm，为V9接管帧最大误差；所选物体可见顶部比最高可见实例低238.45mm。case471/repeat2仍选中错误区域，误差−151.54mm。部分远距离双目样本的传感器噪声代理σ达到约0.34–0.48m，使“3σ内有支撑”非常宽松：空间平滑和标准化残差小不等于绝对高度准确。这既是候选排序/风险模型不足，也受当前噪声代理和远距可观测性限制；不能直接当作真实相机实测结论。
5. 错误区域已纳入训练，并不意味着身份错误已经消除。248个V9接管帧中240个符合物理漂浮物候选定义，182个来自与可见最高实例相差≤20mm的实例。仍有8个非物理/混合候选接管，其中2个超过容差，其余也不能被算成正确识别。

对所有接管候选，以预测风险是否包住其到真实物理最高高度的绝对误差进行事后检查：V9为89.52%，同策略单帧89.34%，V8为80.00%。这支持联合风险目标比旧条件风险更贴近完整错误来源，但各版本接管群体不同，不能把9.52个百分点全归因于训练目标；89.52%也不是覆盖所有帧的校准保证，尤其不包含回退误差。

### 多帧确认的真实收益

新测试8帧最终采用小候选确认通道，涉及主动双目、结构光、ToF；相对同策略单帧，改善>5mm为3帧、退化>5mm为3帧、差异≤5mm为2帧。没有任何通过/失败状态改变，首曝光与单帧输出差异为0。

改善例：结构光case549/repeat2为62.04→32.64mm，case189/repeat3为45.69→8.54mm，ToF case393/repeat3为26.72→12.88mm。退化例：主动双目case183/repeat1为1.94→23.35mm，repeat3为2.03→15.85mm，case93/repeat3为4.13→15.33mm。

V9相对同策略单帧MAE只降低0.07mm，配对95%区间[−0.44,0.26]mm，不能声称多帧已经有效改善总体精度。它只确认重复可见性，不融合高度、不提高原始点云密度，也无法消除持续同向错误。当前RGB静态、几何静态，尚未验证漂浮物运动、遮挡和实例交换。

### 历史反例与持续错误区域诊断

历史样本不参与本次选参，也不并入独立主表。V8旧测试case303/repeat0中，V8研究策略误差1288.13mm，V4为4.74mm、V5/V8主策略为2.49mm、V9为9.37mm。旧V5测试case1023/repeat0中，V5/V8主策略3369.43mm，V9回退72.02mm；修复巨峰但仍非高精度。其他旧例仍可有约0.24–0.36m低估，不应只展示已修复的两帧。

另用case303同一错误区域作4曝光持续性探针：在原有带噪深度上加入0.25倍传感器噪声的新扰动，错误区域不被人为移除。V8研究策略误差依次1288.13、1289.14、1.05、0.09mm；V9为9.37、4.73、8.24、4.25mm，且与V9单帧相同。说明这次没有靠重复投票放行旧巨峰，但不能把4次共享底噪的扰动称为新的独立物理错误回波数据，也不能隔离硬约束和联合风险各自的贡献。
