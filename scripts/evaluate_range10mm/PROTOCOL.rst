正式ToF测试协议：0.1-9 m液深、固定10 mm标定误差
================================================

本目录是正式评估入口，测量算法仍使用正式V14。协议修订不意味着算法精度提升。

边界与采样
----------
实际底面相对平均液深限定0.1-9 m；相机到底面继续使用0.9-10 m设计范围。
保留顶部固定相机、既有8类单场景及11种已声明复合组合，ToF为唯一传感器基准。
25个场景/程度小类各100帧。按[0.1,1)、[1,2)、...、[8,9]设置配额12、11、...、11。
先抽液深再抽可实现安装，三种容器形状、尺寸、偏心及噪声机制继续随机化。
高液位受相机10 m上限约束，容器尺寸从明确的可实现范围抽样，不把原容器自动缩小。
完整槽口可见不是强制条件；必须有空槽建模所需的可见底面或可见槽口边缘/独立尺寸。

标定与复用
----------
底面距离、容器尺寸、校验长度和4个非零已知液深标签均采用固定零均值截断高斯：
截断前sigma=0.01/3 m，拒绝重抽超过正负0.01 m的误差，不对测量输出裁剪或强制归零。
确认空槽的标签仍为0，零位不确定度由底面基准承载。点击sigma=0.3 px、重力分量sigma=0.001不变。
实际标注逐量记录用于预算核验。旧渲染输入按原输入顺序及新深度配额选择，不查看测量误差。
旧的距离比例高斯标定结果不能仅因数值误差小于10 mm而当作新分布结果复用。
本轮所有ideal/operator_noise测量重新运行；旧图像复用与旧测量结果复用分别统计。
旧域外和配额外输入只退出新正式队列，原实验归档保留，不冒充输入资格失败。

输入资格与指标
--------------
资格在推理前由模拟可见性和真实回波来源判定，不能按预测误差排除。
普通液面需至少30个真实返回、空间跨度至少3 px、液面失效不超过50%；
有漂浮物时最高实例至少3个真实返回。原生相位ROI需共同先验/当前调制支撑至少64点。
合法、证据充分输入上的初始化或测量失败保留并计入覆盖率，不补采替换失败结果。
容差沿用液深max(20 mm,2%H)，波面液深及最高高度max(50 mm,5%对应真值)。
波面或漂浮物的功能通过要求两个高度均通过；透明/半透明只承诺相位液深输出。
理想标定仅是同图诊断对照；主统计使用固定10 mm标定扰动。
相位模拟仍是独立解析代理，不是完整光谱渲染或真机认证。
时延测量包含暖态资格/分类/测量，排除初始化、渲染、磁盘、网络和界面。

执行
----
从服务器项目根目录运行，现有环境与旧输入归档需可访问::

    python scripts/evaluate_range10mm/run.py --root /root/autodl-tmp/liquid-depth-artifacts/<new-run> --prepare --capture --evaluate

逐帧数据、选择清单、资格排除原因、代码/权重哈希和配对统计保存在指定输出目录。
新安装的空/湿图像外参及内参一致性须通过审计，测试当前湿真值不进入测量器。
